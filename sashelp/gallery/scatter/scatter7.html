散点图 - 海氏法则图

简介

海氏法则图用于评价药物性肝损伤风险. 横轴为峰值 ALT 或 AST 相对于正常值上限(ULN)的倍数, 纵轴为峰值总胆红素相对于正常值上限(ULN)的倍数, 两轴均使用对数刻度, 并按治疗组区分散点.

参数

名称 类型 描述
X=<var>必需参数峰值 ALT 或 AST 相对于 ULN 的倍数
Y=<var>必需参数峰值 TBIL 相对于 ULN 的倍数
CLASS=<var>可选参数治疗组变量, 未指定时, 全部数据被视为属于同一组别
XMIN=<num>可选参数X 轴最小刻度值
XMAX=<num>可选参数X 轴最大刻度值
XINC=<num>可选参数对数 X 轴未使用此参数
YMIN=<num>可选参数Y 轴最小刻度值
YMAX=<num>可选参数Y 轴最大刻度值
YINC=<num>可选参数对数 Y 轴未使用此参数

注意事项

海氏法则图通常以 ALT 或 AST 峰值超过 3×ULN 且 TBIL 峰值超过 2×ULN 作为重要参考区域.

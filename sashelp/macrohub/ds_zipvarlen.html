ds_zipvarlen

将数据集字符变量的长度压缩至最优长度

依赖: ds_attr, ds_varlist

名称

ds_zipvarlen

简介

就地修改 DATA= 指定的数据集，将所有字符变量的长度调整为数据中实际使用的最大长度（按字节计算），并可选地重建格式与输入格式。宏不返回值，修改直接写回原数据集；该修改不可逆。

语法

%ds_zipvarlen(data=<dataset>)

该宏为过程式宏，直接修改输入数据集，不返回值。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待修改的 SAS 数据集名，仅支持数据集，不支持视图。
DELFMT= 可选参数 Y 是否删除字符变量的现有格式并改为 $n.，n 为压缩后的长度。
Y：删除并设置新格式。
N：保留现有格式。
DELINFMT= 可选参数 Y 是否删除字符变量的现有输入格式并改为 $n.，n 为压缩后的长度。
Y：删除并设置新输入格式。
N：保留现有输入格式。

用法示例

示例 1：压缩字符变量长度并重建格式

data work.zip;
  length a $20 b $30;
  a='abc';    b='xx'; output;
  a='abcdef'; b='';   output;
run;

%ds_zipvarlen(data=work.zip)

proc sql;
  select name, length, format, informat
  from dictionary.columns
  where libname='WORK' and memname='ZIP'
  order by varnum;
quit;

运行结果（WORK.ZIP 变量属性）：

变量名长度格式输入格式
a6$6.$6.
b2$2.$2.

a 的实际最长值为 abcdef（6 字节），b 为 xx（2 字节），因此长度被压缩为 6 与 2；默认 DELFMT=Y、DELINFMT=Y 将格式与输入格式改为对应的 $n.。

示例 2：保留原有格式与输入格式

data work.zip2;
  length a $20;
  attrib a format=$20. informat=$20.;
  a='abc'; output;
run;

%ds_zipvarlen(data=work.zip2,delfmt=N,delinfmt=N)

proc sql;
  select name, length, format, informat
  from dictionary.columns
  where libname='WORK' and memname='ZIP2'
  order by varnum;
quit;

运行结果（WORK.ZIP2 变量属性）：

变量名长度格式输入格式
a3$20.$20.

长度压缩为实际最长值 3，但 DELFMT=N 与 DELINFMT=N 保留了原来的 $20. 格式与输入格式。

示例 3：处理 0 观测数据集

data work.empty;
  length a $20;
  if 0 then output;
run;

%ds_zipvarlen(data=work.empty)

proc sql;
  select name, length, format, informat
  from dictionary.columns
  where libname='WORK' and memname='EMPTY'
  order by varnum;
quit;

运行结果（WORK.EMPTY 变量属性）：

变量名长度格式输入格式
a1$1.$1.

数据集有字符变量但观测数为 0 时，宏将长度设为 1，格式与输入格式设为 $1.。

注意事项

  • 宏会不可逆地修改输入数据集。
  • DELFMT=Y 删除格式并改为 $n.，N 保留原格式；DELINFMT=Y 删除输入格式并改为 $n.，N 保留原输入格式。
  • DATA= 仅支持数据集，不支持视图。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • 宏按观测值推算字符变量的目标长度，假定数据集中存在可供取样的值。0 观测数据集没有可用取值，其所有字符变量会被压缩为长度 1（默认参数下格式与输入格式也同步改为 $1.），且该修改不可逆。

2. 临时变量与临时数据集冲突风险

  • 宏内部固定使用 _eof_、_chr_、_len_、_zip_ 作为工作变量。输入数据集若含同名变量，宏不会事先检测，运行会在处理阶段失败。

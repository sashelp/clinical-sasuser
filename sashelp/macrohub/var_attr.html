名称

var_attr

简介

返回指定数据集中指定变量的某一属性值。宏以函数方式返回文本结果：ATTR=NUM 返回变量位置（从 1 开始），NAME 返回变量名，TYPE 返回 C 或 N，LENGTH 返回变量长度，FORMAT 与 INFORMAT 返回格式名与输入格式名（未设置时返回空值），LABEL 返回变量标签。返回值可直接用于 %put、%let、%if 等宏语句。

语法

%var_attr(data=<dataset>, var=<variable>, attr=<attribute>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待查询的 SAS 数据集名，仅支持数据集，不支持视图。
VAR= 必需参数 无 待查询的变量名，必须存在于 DATA= 指定的数据集中。
ATTR= 必需参数 无 待获取的属性名，不区分大小写，可取以下值：
NUM：变量位置。
NAME：变量名。
TYPE：变量类型（C 或 N）。
LENGTH：变量长度。
FORMAT：变量格式名。
INFORMAT：变量输入格式名。
LABEL：变量标签。

用法示例

示例 1：获取变量位置、类型与名称

%put NOTE: NAME 位置 = %var_attr(data=sashelp.class,var=name,attr=NUM);
%put NOTE: NAME 类型 = %var_attr(data=sashelp.class,var=name,attr=TYPE);
%put NOTE: NAME 名称 = %var_attr(data=sashelp.class,var=name,attr=NAME);

运行结果：

NOTE: NAME 位置 = 1
NOTE: NAME 类型 = C
NOTE: NAME 名称 = Name

sashelp.class 中 Name 是第 1 个变量且为字符型，因此 NUM 返回位置 1，TYPE 返回 C，NAME 返回变量原始大小写 Name。

示例 2：获取格式、输入格式与标签

data work.attr;
  length subjid $8;
  attrib age label='年龄（岁）' format=8.2 informat=best32.;
  subjid='S01'; age=45.6;
run;

%put NOTE: AGE 格式 = [%var_attr(data=work.attr,var=age,attr=FORMAT)];
%put NOTE: AGE 输入格式 = [%var_attr(data=work.attr,var=age,attr=INFORMAT)];
%put NOTE: AGE 标签 = [%var_attr(data=work.attr,var=age,attr=LABEL)];

运行结果：

NOTE: AGE 格式 = [8.2]
NOTE: AGE 输入格式 = [BEST32.]
NOTE: AGE 标签 = [年龄（岁）]

ATTR=FORMAT 返回 8.2，INFORMAT 返回 BEST32.，LABEL 返回中文标签。若变量没有设置对应属性，则返回空值（方括号内为空）。

示例 3：在宏内部按变量类型分支

data work.attr;
  length subjid $8;
  attrib age label='年龄（岁）' format=8.2 informat=best32.;
  subjid='S01'; age=45.6;
run;

%macro check_var(data=,var=);
  %if %qupcase(%var_attr(data=&data.,var=&var.,attr=TYPE))=C %then %do;
    %put NOTE: &var. 为字符型变量。;
  %end;
  %else %do;
    %put NOTE: &var. 为数值型变量。;
  %end;
%mend check_var;

%check_var(data=work.attr,var=subjid)
%check_var(data=work.attr,var=age)

运行结果：

NOTE: subjid 为字符型变量。
NOTE: age 为数值型变量。

%var_attr 返回 C 或 N，宏用 %qupcase() 统一大小写后与 C 比较，从而进入不同分支。

注意事项

  • 依赖宏 %var_exist。
  • DATA= 仅支持数据集，不支持视图。
  • ATTR= 仅支持 NUM、NAME、TYPE、LENGTH、FORMAT、INFORMAT、LABEL。

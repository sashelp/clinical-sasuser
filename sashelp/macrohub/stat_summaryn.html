名称

stat_summaryn

简介

对定量变量按 CLASS= 分组计算描述性统计量，并可通过 BY= 产生分组结果；STATIS= 控制要输出的统计量及其顺序。输出为长表：每个 BY 组、分析变量、统计量一行，分组水平转置为 TRT<index> 列，合计组为 TRT<TOTCLASSID>；_TESTV_、_TESTP_、_TESTM_ 存放假设检验统计量、P 值与检验方法。宏不返回值，结果写入 OUT= 数据集。

语法

%stat_summaryn(data=<dataset>, var=<variables>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称类型默认值描述
DATA= 必需参数 无 输入数据集名，仅支持数据集。
OUT= 可选参数 _DATA_ 输出数据集名。
BY= 可选参数 无 BY 分组变量，可指定多个变量（空格分隔），每个 BY 组单独输出结果。
CLASS= 可选参数 无 定义分组与比较的变量，仅支持一个；不指定时所有观测作为一个总体分析。
VAR= 必需参数 无 分析变量列表，多个变量以空格分隔；输出顺序与书写顺序一致，变量必须为数值型。
STATIS= 可选参数 N_NMISS MEAN_STD MEDIAN Q1_Q3 MIN_MAX 要显示的统计量及其输出顺序。有效值：
N、NMISS、N_NMISS、MEAN、LCLM、UCLM、CLM、MEDIAN、Q1、Q3、MIN、MAX、RANGE、MIN_MAX、SUM、STDDEV、STDERR、VAR、CV、MEAN_STD、Q1_Q3、MED_Q1_Q3、GM、GM_LCLM、GM_UCLM、GM_CLM、GM_STD、GM_STDDEV、GM_CV。
CI_ALPHA= 可选参数 0.05 LCLM、UCLM、CLM 的置信水平，取值 0 至 1。
MAXDEC= 可选参数 4 统计量的最大小数位数，取值 0 至 9。
TEST= 可选参数 NONE 组间假设检验方法。
NONE：不检验。
AUTO：先检验正态性，再按变量选择 PAR 或 NPAR。
PAR：参数检验，两组用 t 检验，多组用 ANOVA。
NPAR：非参数检验，两组用 Wilcoxon，多组用 Kruskal-Wallis。
TEST_ALPHA= 可选参数 0.05 假设检验的显著性水平，同时用于 TEST=AUTO 的正态性判断，取值 0 至 1。
TOTCLASSID= 可选参数 0 合计组的数字索引，作为 TRT 列的后缀。
TOTCLASSLAB= 可选参数 Total 合计组的列标签。
RAWDECSOURCE= 可选参数 OVERALL 原始小数位数的计算方式。
OVERALL：所有数据共用一个最大原始小数位数。
BY：每个 BY 组分别计算最大原始小数位数。
MINMAXFMT= 可选参数 无 MIN、MAX、SUM 的显示格式；留空时按 MAXDEC 指定的小数位四舍五入。
POSFMT= 可选参数 无 位置统计量（均值、中位数、四分位数、置信限）的显示格式；留空时为 24.d，d 为最大原始小数位且不超过 MAXDEC。
SCAFMT= 可选参数 无 尺度统计量（标准差、标准误）的显示格式；留空时为 24.d，d 为最大原始小数位且不超过 MAXDEC。
CVFMT= 可选参数 16.2 变异系数的显示格式。
SHOWDENOM= 可选参数 Y 是否在分类变量标签后显示 (N=#)，# 为 n+nmiss，取 Y 或 N。
DENOMDLM= 可选参数 @ 分类标签与 (N=#) 文本之间的分隔字符。
DEBUG= 可选参数 0 是否保留中间数据集。
0：结束时删除中间数据集。
1：保留中间数据集以便排查。

注意事项

  • CLASS= 仅支持一个变量；未指定 CLASS= 时所有观测作为一个总体分析，TEST= 被强制为 NONE。
  • 合计组自动生成；TOTCLASSID= 不能与各分组水平的数字索引冲突。
  • 几何统计量（GM*）仅在 STATIS= 请求时计算；非正值不参与对数变换。
  • TEST=AUTO 按每个分析变量的最小正态性 P 值是否大于或等于 TEST_ALPHA=，分别选择参数检验或非参数检验。
  • 输出每个 BY 组、分析变量、统计量一行；分组水平转置为 TRT<index> 列，合计组为 TRT<TOTCLASSID>；SHOWDENOM=Y 时列标签附加 (N=#)。
  • 检验统计量、P 值与检验方法只写在各分析变量的第一条观测上；无法计算的统计量显示为 N/A。
  • ANOVA 通过 PROC NPAR1WAY 的 ANOVA 选项完成，结果与 PROC ANOVA 相同，但运行更快。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • CLASS= 仅支持一个变量；未指定 CLASS= 或仅有一个非缺失水平时，所有观测作为一个总体分析，且 TEST= 被强制为 NONE。
  • TOTCLASSID= 不得与各分组水平的数字索引重复；取值冲突时合计组的 TRT 列会与某个分组列同名，导致列冲突或结果被错误归并。
  • 几何统计量（GM*）仅使用大于 0 的观测做对数变换，0 与负值被自动排除。请求几何统计量时，其样本量与 N、均值等统计量不一致，且排除过程不产生提示。

2. 临时变量与临时数据集冲突风险

  • 宏会创建并覆盖固定名称的中间数据集（名称以 STAT_SUMMARYN_ 开头），并在 DEBUG=0 时删除 WORK 中所有以 STAT_SUMMARYN_ 开头的数据集；WORK 中该前缀的自有数据集会被覆盖或误删。
  • 未指定 CLASS= 时，宏用临时变量 _CLASS_ 承担分组，并用 _BYIDX_、_VARIDX_、_VARVAL_、_DECLEN_ 记录分组、变量与取值。若输入数据集已含这些同名变量，其原值会在处理中被覆盖，导致分组或变量归属错乱。

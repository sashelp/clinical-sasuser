名称

var_coexist

简介

判断一组变量是否同时存在于指定的数据集中，并可选择校验变量类型。宏以函数方式返回数值结果：RESULTTYPE=BOOLEAN（默认）时，全部变量存在且类型符合返回 1，否则返回 0；RESULTTYPE=POSITION 时，全部变量符合返回 1，否则返回 -i，i 为第一个不存在或类型不符的变量序号。返回值可直接用于 %if 条件判断，也可通过 %let 或 %put 获取。

语法

%var_coexist(data=<dataset>, var=<variables>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待检查的 SAS 数据集名，仅支持数据集，不支持视图。
VAR= 必需参数 无 待检查的变量名列表，多个变量以空格分隔，按书写顺序依次检查。
RESULTTYPE= 可选参数 BOOLEAN 返回结果的形式。
BOOLEAN：全部变量存在且类型符合时返回 1，否则返回 0。
POSITION：全部变量符合时返回 1，否则返回 -i，i 为第一个不存在或类型不符的变量序号。
TYPE= 可选参数 ALL 期望的变量类型。
ALL：不校验变量类型。
C：要求为字符型。
N：要求为数值型。

用法示例

示例 1：判断多个变量是否同时存在

%put NOTE: NAME SEX AGE = %var_coexist(data=sashelp.class,var=name sex age);
%put NOTE: NAME SEX ABC = %var_coexist(data=sashelp.class,var=name sex abc);

运行结果：

NOTE: NAME SEX AGE = 1
NOTE: NAME SEX ABC = 0

默认 RESULTTYPE=BOOLEAN：三个变量都存在时返回 1；ABC 不存在时返回 0。

示例 2：同时校验变量类型

%put NOTE: NAME SEX type=C = %var_coexist(data=sashelp.class,var=name sex,type=C);
%put NOTE: NAME AGE type=C = %var_coexist(data=sashelp.class,var=name age,type=C);

运行结果：

NOTE: NAME SEX type=C = 1
NOTE: NAME AGE type=C = 0

TYPE=C 要求列表中的变量全部为字符型。Name 与 Sex 均为字符型，返回 1；Age 为数值型，返回 0。

示例 3：定位第一个不满足条件的变量

%put NOTE: 第一个不满足的变量位置 = %var_coexist(data=sashelp.class,var=name abc age,resulttype=POSITION);

运行结果：

NOTE: 第一个不满足的变量位置 = -2

RESULTTYPE=POSITION 时，Name 存在、ABC 是第 2 个变量且不存在，因此返回 -2；全部变量符合时返回 1。

注意事项

  • BOOLEAN 返回 1 或 0；POSITION 全部符合返回 1，否则返回 -i，i 为第一个不存在或类型不符的变量序号。
  • DATA= 仅支持数据集，不支持视图。
  • TYPE= 仅支持 ALL、C、N。
  • RESULTTYPE= 仅支持 BOOLEAN、POSITION。

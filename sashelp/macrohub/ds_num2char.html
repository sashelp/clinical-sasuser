名称

ds_num2char

简介

将 DATA= 中指定的数值变量转换为字符变量，并写入 OUT= 数据集。转换后的字符变量长度固定为 200，并在输出数据集中排在其余原始变量之前；变量顺序按 VAR= 的书写顺序排列。宏不返回值，结果保存在输出数据集中。

语法

%ds_num2char(data=<dataset>, var=<variables>)

该宏为过程式宏，直接创建输出数据集，不返回值。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 输入 SAS 数据集名，仅支持数据集，不支持视图。
VAR= 必需参数 无 待转换的数值变量列表，多个变量以空格分隔。源程序虽将其列为可选参数，但省略时内部校验会终止提交，因此实际必须指定。
OUT= 可选参数 &DATA. 输出数据集名。默认与输入数据集同名，会覆盖输入数据集，建议显式指定。
VALUE= 可选参数 FORMATTED 转换取值方式。
FORMATTED：使用格式化后的显示值；变量未赋格式时按 BEST12. 输出。
INTERNAL：使用数值的内部表示。
MISSING= 可选参数 NULL 缺失值处理方式。
NULL：将缺失值转换为空字符串。
ASIS：保留格式化后的缺失表示，如 .、.A 等。

用法示例

示例 1：将两个数值变量转换为字符变量

%ds_num2char(data=sashelp.class,out=work.class_c,var=age height)

proc print data=work.class_c(obs=3);
run;

运行结果（WORK.CLASS_C 前 3 行）：

观测AgeHeightNameSexWeight
11469AlfredM112.5
21356.5AliceF84.0
31365.3BarbaraF98.0

Age 与 Height 已转为字符型并按 VAR= 顺序排在输出数据集前面，其余变量 Name、Sex、Weight 保持原顺序；转换后的变量长度为 200。

示例 2：保留内部值并保留缺失表示

data work.num;
  length id $4;
  id='01'; x=1.25; output;
  id='02'; x=.;    output;
run;

%ds_num2char(data=work.num,out=work.num_i,var=x,value=INTERNAL,missing=ASIS)

proc print data=work.num_i;
run;

运行结果（WORK.NUM_I）：

观测xid
11.2501
2.02

VALUE=INTERNAL 直接取数值的内部值，不受格式影响；MISSING=ASIS 使缺失值保留为 . 文本。转换变量 x 排在原变量 id 之前。

示例 3：转换全部数值变量

%let nvars=%ds_varlist(data=sashelp.class,type=N);
%put NOTE: 数值变量 = &nvars.;
%ds_num2char(data=sashelp.class,out=work.class_c2,var=&nvars.)

proc sql;
  select name, type, length
  from dictionary.columns
  where libname='WORK' and memname='CLASS_C2'
  order by varnum;
quit;

运行结果：

NOTE: 数值变量 = Age Height Weight

运行结果（WORK.CLASS_C2 变量清单）：

变量名类型长度
Agechar200
Heightchar200
Weightchar200
Namechar8
Sexchar1

%ds_varlist 返回全部数值变量 Age Height Weight，宏将其依次转换为长度为 200 的字符变量，未转换的 Name、Sex 保持原长度。

注意事项

  • VAR= 指定待转换的数值变量，多个变量以空格分隔。
  • OUT= 默认与 DATA= 相同。
  • VALUE= 仅支持 FORMATTED、INTERNAL；MISSING= 仅支持 NULL、ASIS。
  • 宏内部使用 _eof_、_chr_、_num_、__tmp: 等名称，输入数据集变量名不能与之冲突，否则宏可能失败。
  • 转换后变量顺序会改变。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • OUT= 指定的数据集会被直接覆盖，宏不检查其是否已存在；默认 OUT=&DATA. 意味着未指定 OUT= 时输入数据集被原地替换。

2. 临时变量与临时数据集冲突风险

  • 宏内部固定使用 _eof_、_chr_、_num_ 以及 __tmp1 … __tmpN 作为工作变量。输入数据集若含同名变量，宏不会事先检测，运行会直接失败且得不到输出结果。

名称

dir_exist

简介

判断指定目录是否存在。宏以函数方式返回 1 或 0：目录存在返回 1，否则返回 0。目录名无需加引号，宏会去掉外层成对的引号。

语法

%dir_exist(dir=<directory>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DIR= 必需参数 无 完整目录路径，不需要加引号；即使加了一对引号也会被去除。支持在路径中使用 SAS 环境变量。

用法示例

示例 1：判断目录是否存在

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;

%put NOTE: 目录存在 = %dir_exist(dir=%sysfunc(pathname(dirdemo)));

运行结果：

NOTE: 目录存在 = 1

DIRDEMO 对应的物理目录已创建，宏返回 1。

示例 2：判断不存在的目录

%put NOTE: 不存在目录 = %dir_exist(dir=%sysfunc(pathname(work))\not_exist);

运行结果：

NOTE: 不存在目录 = 0

在 WORK 临时目录下并不存在 not_exist 子目录，宏返回 0。

示例 3：目录名带引号传入

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;

%put NOTE: 带引号目录 = %dir_exist(dir="%sysfunc(pathname(dirdemo))");

运行结果：

NOTE: 带引号目录 = 1

目录名即使带一对引号，宏也会先去除外层引号再判断，因此结果与不带引号一致。

注意事项

  • 目录存在返回 1，否则返回 0。
  • 支持在 DIR= 中使用 SAS 环境变量，不支持操作系统环境变量。
  • 目录名无需加引号；宏会去掉外层成对引号。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • 宏只判断路径是否为可访问的目录；DIR= 指向已存在的文件时返回 0，因此返回值无法区分“路径不存在”与“路径存在但不是目录”。

2. 临时变量与临时数据集冲突风险

  • 宏会临时占用固定名称的文件引用 _dummy_，结束时释放。若会话中已分配同名文件引用，其原有分配会被覆盖并清除。

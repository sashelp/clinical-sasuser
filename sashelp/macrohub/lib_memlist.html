名称

lib_memlist

简介

返回指定逻辑库的成员名列表，成员名以空格分隔并统一为大写。可通过 TYPE= 过滤成员类型，通过 PATTERN= 使用 Perl 正则表达式过滤成员名。宏基于 SASHELP.VMEMBER 读取当前会话可见的成员。

语法

%lib_memlist(library=<library>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
LIBRARY= 必需参数 无 已分配的逻辑库引用名。
TYPE= 可选参数 无 成员类型过滤条件，不区分大小写。
不指定：返回所有类型成员。
DATA：SAS 数据集。
VIEW：SAS 视图。
CATALOG：SAS 目录。
ITEMSTOR：SAS 项目存储。
MDDB：SAS 多维数据库。
PATTERN= 可选参数 无 成员名过滤的正则表达式，需包含分隔符，例如 /^ADSL/。

用法示例

示例 1：列出指定名称的成员

%put NOTE: 匹配成员 = [%lib_memlist(library=sashelp,pattern=/^CLASS$/)];

运行结果：

NOTE: 匹配成员 = [CLASS]

sashelp 中存在名为 CLASS 的数据集，正则 /^CLASS$/ 只匹配完整名称，因此返回 CLASS。

示例 2：只列出数据集成员

options dlcreatedir;
libname libmem "%sysfunc(pathname(work))\libmem";

data libmem.demo1; x=1; run;
data libmem.demo2; x=2; run;

%put NOTE: DATA 成员 = [%lib_memlist(library=libmem,type=DATA,pattern=/^DEMO/)];

运行结果：

NOTE: DATA 成员 = [DEMO1 DEMO2]

逻辑库 LIBMEM 中有两个数据集，TYPE=DATA 过滤掉其他成员类型，PATTERN=/^DEMO/ 匹配名称以 DEMO 开头的成员，返回 DEMO1 DEMO2。

示例 3：只列出视图成员

options dlcreatedir;
libname libmem "%sysfunc(pathname(work))\libmem";

data libmem.demo1; x=1; run;
proc sql;
  create view libmem.demo_v as select * from libmem.demo1;
quit;

%put NOTE: VIEW 成员 = [%lib_memlist(library=libmem,type=VIEW,pattern=/^DEMO/)];

运行结果：

NOTE: VIEW 成员 = [DEMO_V]

DEMO_V 是 SQL 视图，TYPE=VIEW 只返回视图成员，因此输出 DEMO_V。

注意事项

  • 返回的成员名统一为大写。
  • TYPE= 仅支持 DATA、VIEW、CATALOG、ITEMSTOR、MDDB。
  • PATTERN= 为正则表达式过滤条件。

已知风险

以下列出当前版本已知但未修复的问题、使用约束与冲突风险。

1. 对输入参数的强假设

  • LIBRARY= 必须是当前会话中已经分配的逻辑库；未分配的逻辑库引用会被直接判为不存在并终止。
  • PATTERN= 必须带定界符（例如 /^AE/）；不带定界符时会被判为非法正则表达式并终止。

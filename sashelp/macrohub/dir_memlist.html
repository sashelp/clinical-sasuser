名称

dir_memlist

简介

按层遍历指定目录，将文件与子目录信息写入 OUT= 数据集。MAXDEPTH= 控制遍历深度：1 表示只处理当前目录，2 表示包含一级子目录，依此类推；MEMINFO=N 时输出路径、层级、名称、扩展名与类型，MEMINFO=Y 时 Windows 还会输出文件大小、修改时间、创建时间、RECFM 与 LRECL，Linux 还会输出所有者、用户组与权限。宏不返回值。

语法

%dir_memlist(dir=<directory>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称 类型 默认值 描述
DIR= 必需参数 无 待遍历的完整目录路径，不需要加引号；即使加了一对引号也会被去除。支持在路径中使用 SAS 环境变量。
MAXDEPTH= 可选参数 1 最大遍历层级，必须为正整数。1 表示只遍历当前目录，2 表示包含一级子目录，依此类推。
MEMINFO= 可选参数 N 是否获取成员详细信息，不区分大小写。
N：只输出 path、depth、name、ext、type。
Y：Windows 增加 filesize、modtm、recfm、lrecl、crdtm；Linux 增加 filesize、modtm、owner、groupname、permission，并额外包含根目录记录。
OUT= 可选参数 _DATA_ 输出数据集名。
EXT= 可选参数 无 按文件扩展名过滤，填写不带点号的扩展名，例如 sas7bdat、sas。

用法示例

示例 1：列出目录中的数据集文件

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;
data dirdemo.ds2; x=2; run;

%dir_memlist(dir=%sysfunc(pathname(dirdemo)),out=work.mem1,
             ext=sas7bdat,maxdepth=1,meminfo=N)

proc print data=work.mem1;
run;

运行结果（WORK.MEM1）：

观测pathdepthnameexttype
1<WORK>\dirdemo\ds1.sas7bdat1ds1.sas7bdatSAS7BDATFile
2<WORK>\dirdemo\ds2.sas7bdat1ds2.sas7bdatSAS7BDATFile

MAXDEPTH=1 只遍历当前目录，EXT=sas7bdat 过滤出两个 SAS 数据集；MEMINFO=N 时只输出 path、depth、name、ext、type 五列。表内 <WORK> 代表当前 WORK 临时目录。

示例 2：获取文件大小与时间信息

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;
data dirdemo.ds2; x=2; run;

%dir_memlist(dir=%sysfunc(pathname(dirdemo)),out=work.mem2,
             maxdepth=1,meminfo=Y)

proc print data=work.mem2;
run;

运行结果（WORK.MEM2，节选列）：

观测pathdepthnametypefilesizemodtm
1<WORK>\dirdemo0Directory..
2<WORK>\dirdemo\ds1.sas7bdat1ds1.sas7bdatFile1310722026-11-03T23:00:59
3<WORK>\dirdemo\ds2.sas7bdat1ds2.sas7bdatFile1310722026-11-03T23:00:59

MEMINFO=Y 时除文件信息外，还会输出一条 DEPTH=0 的根目录记录；Windows 下同时生成 filesize、modtm、recfm、lrecl、crdtm。

示例 3：递归两级目录

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;
data dirdemo.ds2; x=2; run;

libname dirsub "%sysfunc(pathname(dirdemo))\sub";
data dirsub.ds3; x=3; run;

%dir_memlist(dir=%sysfunc(pathname(dirdemo)),out=work.mem3,
             ext=sas7bdat,maxdepth=2,meminfo=N)

proc print data=work.mem3;
run;

运行结果（WORK.MEM3）：

观测pathdepthnameexttype
1<WORK>\dirdemo\ds1.sas7bdat1ds1.sas7bdatSAS7BDATFile
2<WORK>\dirdemo\ds2.sas7bdat1ds2.sas7bdatSAS7BDATFile
3<WORK>\dirdemo\sub\ds3.sas7bdat2ds3.sas7bdatSAS7BDATFile

MAXDEPTH=2 在一级目录之外继续遍历子目录，因此 sub\ds3.sas7bdat 以 DEPTH=2 出现在结果中。

注意事项

  • MEMINFO=Y 时，Windows 输出 filesize、modtm、recfm、lrecl、crdtm；Linux 输出 filesize、modtm、owner、groupname、permission。
  • 仅支持 Windows 与 Linux 操作系统。
  • 支持在 DIR= 中使用 SAS 环境变量，不支持操作系统环境变量。
  • 目录名无需加引号；宏会去掉外层成对引号。
  • MAXDEPTH= 为最大目录层级。

已知风险

1. 已知但未修复的风险

  • 这是 SAS 软件的已知缺陷：使用 SAS 9.4M7 Unicode 会话且运行于 Windows 时，可能无法获取文件的大小、修改时间、权限等属性。

名称

stat_rateci

简介

对二分类分析变量，按 CLASS= 分组计算 LEVEL= 指定水平的样本率与置信限，并可为任意两个分组计算率差及其置信限。输出为长表：_METHOD_ 标识方法，_PROP_ 为率或率差（百分比），_CL_L_ 与 _CL_U_ 为置信下限与上限，_ALPHA_ 为显著性水平，_SOURCE_ 标识计算来源（PROC FREQ 或 MANUAL）。宏不返回值，结果写入 OUT= 数据集。

语法

%stat_rateci(data=<dataset>, class=<variable>, var=<variable>, level=<level>)

LEVEL= 必须使用带引号的格式化值，例如 level='Y'，否则宏会终止并提示格式错误。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 输入数据集名，仅支持数据集，且观测数必须大于 0。
OUT= 可选参数 _DATA_ 输出数据集名。
BY= 可选参数 无 分组变量，可指定多个变量；每个 BY 组分别计算。
CLASS= 必需参数 无 定义分组分析的变量，仅支持一个变量。
VAR= 必需参数 无 分析变量，仅支持一个变量，且格式化后必须恰好有 2 个水平。
LEVEL= 必需参数 无 要计算率的目标水平，须使用带引号的格式化值，且必须存在于分析变量中。
SMETHOD= 可选参数 EXACT 单样本率置信限方法，可指定多个方法（空格分隔），不区分大小写。
ALL、NONE、AC、BLAKER、EXACT、JEFFREYS、LR、LOGIT、MIDP、WALD、WILSON。
SALPHA= 可选参数 0.05 单样本率置信限的显著性水平，取值 0 至 1。
DMETHOD= 可选参数 WALD 率差置信限方法，可指定多个方法（空格分隔），不区分大小写。
ALL、NONE、AC、EXACT、HA、MN、NEWCOMBE、WALD。
DALPHA= 可选参数 0.05 率差置信限的显著性水平，取值 0 至 1。
DEBUG= 可选参数 0 是否保留中间数据集。
0：结束时删除中间数据集。
1：保留中间数据集以便排查。

用法示例

示例 1：默认方法计算单样本率与率差

data work.resp1;
  length usubjid $4 trt $1 resp $1;
  input usubjid $ trt $ resp $;
  datalines;
S01 A Y
S02 A Y
S03 A Y
S04 A Y
S05 A N
S06 A N
S07 B Y
S08 B Y
S09 B N
S10 B N
S11 B N
S12 B N
;
run;

%stat_rateci(data=work.resp1,out=work.rate1,class=trt,var=resp,level='Y')

proc print data=work.rate1(keep=trt ref_trt _method_ _prop_ _cl_l_ _cl_u_ _source_);
run;

运行结果（WORK.RATE1）：

trtref_trt_method__prop__cl_l__cl_u__source_
AExact66.666722.277895.6728PROC FREQ
ABWald33.3333-20.01086.6768PROC FREQ
BExact33.33334.327277.7222PROC FREQ
BAWald-33.3333-86.67720.0101PROC FREQ

默认 SMETHOD=EXACT 计算各组单样本率的 Exact 置信限；DMETHOD=WALD 计算任意两组的率差及其 Wald 置信限。_prop_ 与置信限均以百分比表示，_source_ 为 PROC FREQ。

注意事项

  • CLASS= 与 VAR= 均只支持一个变量。
  • 若分析变量只有一个水平，需要先为其指定格式以增加到两个水平。
  • LEVEL= 必须使用带引号的格式化值。
  • 置信限基于二项分布假设计算。
  • DMETHOD= 不为 NONE 时计算任意两组的率差；两组频率均为 0 或 100 时使用手工公式，此时 EXACT 置信限不可用。
  • SMETHOD= 支持 ALL、NONE、AC、BLAKER、EXACT、JEFFREYS、LR、LOGIT、MIDP、WALD、WILSON；DMETHOD= 支持 ALL、NONE、AC、EXACT、HA、MN、NEWCOMBE、WALD。

已知风险

以下列出当前版本已知但未修复的问题、使用约束与冲突风险。

1. 已知但未修复的风险

  • 当 DMETHOD= 包含 EXACT，且某两个分组在 LEVEL= 上的频率同为 0 或同为 100 时，差值区间改由手工公式计算，此时不提供 EXACT 置信限，这类极值组合不会输出 EXACT 结果。

2. 对输入参数的强假设

  • VAR= 必须恰好有两个水平，LEVEL= 必须是以引号包围的格式化值且为该两个水平之一；若分析变量只有一个水平，需先为其分配格式以产生第二个水平，否则宏报错中止。
  • CLASS= 仅支持一个变量。当 CLASS= 只有一个非缺失水平时，不会产生任何组间差值结果，只输出单样本率及其置信限。
  • BY= 中的变量须同时存在于输入数据集，且每个 BY 组内应至少有两个分组水平，否则该 BY 组无组间差值结果。

3. 临时变量与临时数据集冲突风险

  • 宏会创建并覆盖固定名称的中间数据集（名称以 STAT_RATECI_ 开头），并在 DEBUG=0 时删除 WORK 中所有以 STAT_RATECI_ 开头的数据集；WORK 中该前缀的自有数据集会被覆盖或误删。

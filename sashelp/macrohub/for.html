名称

for

简介

依次遍历五类数据对象（值列表、数据集、数据集变量描述、目录内容、数值区间），每一轮把当前值赋给 MACRO_VAR_LIST 中指定的宏变量，并展开 DO= 中的代码。宏本身不返回值，其作用是生成 SAS 代码；适用于按数据集中的值或目录中的文件批量生成 REPORT、PRINT 或其他过程代码。

语法

%for(<variables>, in=<object>, do=<code>)

IN= 的对象类型由括号区分：(a b c) 为值列表，[dataset] 为数据集，{dataset} 为数据集变量描述，<directory> 为目录，1:100 为数值区间。DO= 通常用 %nrstr() 包裹，以延迟宏变量解析。

参数说明

名称 类型 默认值 描述
MACRO_VAR_LIST 必需参数（位置参数） 无 每轮循环要赋值的宏变量名列表，多个名称以空格分隔。
IN= 必需参数 无 要遍历的数据对象，按首字符区分类型。
(a b c)：值列表，默认以空格分隔。
[dataset]：数据集，可按观测遍历；支持 WHERE= 限定。
{dataset}：数据集变量描述，可用变量名为 NAME、TYPE、FORMAT、LENGTH、LABEL。
<directory>：目录内容，可用变量名为 FILEPATH、FILENAME、SHORTNAME、EXTENSION、ISDIR。
1:100 或 1:100:2：数值区间，第三个数字为步长。
DO= 必需参数 无 每轮循环要生成的 SAS 代码，通常用 %nrstr() 包裹，使 &var. 在循环时解析。

用法示例

示例 1：遍历值列表

%for(x y, in=(A B C D), do=%nrstr(%put NOTE: x=&x. y=&y.;))

运行结果：

NOTE: x=A y=B
NOTE: x=C y=D

值列表默认以空格分隔，每轮取两个值依次赋给 &X. 与 &Y.，因此执行两轮。DO= 用 %nrstr() 包裹，使宏变量在循环时才解析。

示例 2：遍历数据集观测

%for(name sex, in=[sashelp.class(where=(sex='F'))], do=%nrstr(%put NOTE: name=&name. sex=&sex.;))

运行结果：

NOTE: name=Alice sex=F
NOTE: name=Barbara sex=F
NOTE: name=Carol sex=F
NOTE: name=Jane sex=F
NOTE: name=Janet sex=F
NOTE: name=Joyce sex=F
NOTE: name=Judy sex=F
NOTE: name=Louise sex=F
NOTE: name=Mary sex=F

[ ] 表示按观测遍历数据集，WHERE= 先筛选出女生；每轮把同名变量值赋给 &NAME. 与 &SEX.，共 9 轮。

示例 3：遍历数值区间

%for(i, in=1:10:2, do=%nrstr(%put NOTE: i=&i.;))

运行结果：

NOTE: i=1
NOTE: i=3
NOTE: i=5
NOTE: i=7
NOTE: i=9

1:10:2 表示从 1 到 10、步长为 2，循环变量 &I. 依次取 1、3、5、7、9。

示例 4：遍历数据集变量描述

%for(name type length, in={sashelp.class}, do=%nrstr(%put NOTE: name=&name. type=&type. length=&length.;))

运行结果：

NOTE: name=Name type=2 length=8
NOTE: name=Sex type=2 length=1
NOTE: name=Age type=1 length=8
NOTE: name=Height type=1 length=8
NOTE: name=Weight type=1 length=8

{ } 按变量遍历数据集：NAME 为变量名，TYPE 为 1（数值型）或 2（字符型），LENGTH 为变量长度。

注意事项

  • 值列表默认以空格分隔；其他分隔符使用嵌套括号指定，例如 in=((|)Alice|Bob|Carol|Dave)。显式分隔符允许空项，空格分隔不允许。
  • 遍历数据集变量描述时，MACRO_VAR_LIST 只能使用 NAME、TYPE、FORMAT、LENGTH、LABEL。
  • 遍历目录时，MACRO_VAR_LIST 只能使用 FILEPATH、FILENAME、SHORTNAME、EXTENSION、ISDIR；FILEPATH 使用 Windows 路径分隔符。
  • 该宏为 Jim Anderson 发布的开源宏，使用时请保留原作者署名信息。

已知风险

1. 已知但未修复的风险

  • 数据集遍历支持 WHERE=，但 OBS= 等数据集选项不生效；依赖这些选项控制遍历范围时，结果可能不符合预期。

2. 对输入参数的强假设

  • DO= 中如含 &var.，必须用 %nrstr() 包裹，否则宏变量会在调用 %for 之前被解析，导致遍历值不符合预期。

3. 临时变量冲突风险

  • 该宏会把当前迭代序号写入宏变量 _n_，循环结束后仍保留；同时会创建或覆盖 MACRO_VAR_LIST 中指定的宏变量。若与现有宏变量同名，原值会丢失。

名称

dir_attr

简介

返回指定目录的属性值。DIRECTORY 返回完整目录路径，NMEMS 返回目录下成员（文件与子目录）数量；Linux 下还支持 OWNER、GROUPNAME 与 PERMISSION。目录名无需加引号，宏会去掉外层成对的引号。

语法

%dir_attr(dir=<directory>, attr=<attribute>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DIR= 必需参数 无 完整目录路径，不需要加引号；即使加了一对引号也会被去除。支持在路径中使用 SAS 环境变量。
ATTR= 必需参数 无 待获取的目录属性名，不区分大小写。Windows 支持：
DIRECTORY：完整目录。
NMEMS：目录成员数。
Linux 另支持 OWNER、GROUPNAME、PERMISSION。

用法示例

示例 1：获取完整目录路径

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;

%put NOTE: DIRECTORY = [%dir_attr(dir=%sysfunc(pathname(dirdemo)),attr=DIRECTORY)];

运行结果：

NOTE: DIRECTORY = [.\temp\SAS Temporary Files\_TD8096_BEIJING_\dirdemo]

DIRECTORY 返回该逻辑库对应的完整物理目录；实际路径取决于当前 SAS 会话的 WORK 位置。

示例 2：获取目录成员数

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;
data dirdemo.ds2; x=2; run;

%put NOTE: NMEMS = [%dir_attr(dir=%sysfunc(pathname(dirdemo)),attr=NMEMS)];

运行结果：

NOTE: NMEMS = [2]

目录中有 ds1.sas7bdat 与 ds2.sas7bdat 两个成员，NMEMS 返回 2。

示例 3：目录名带引号传入

options dlcreatedir;
libname dirdemo "%sysfunc(pathname(work))\dirdemo";
data dirdemo.ds1; x=1; run;

%put NOTE: QUOTED DIRECTORY = [%dir_attr(dir="%sysfunc(pathname(dirdemo))",attr=DIRECTORY)];

运行结果：

NOTE: QUOTED DIRECTORY = [.\temp\SAS Temporary Files\_TD8096_BEIJING_\dirdemo]

带引号与不带引号的结果一致，宏会去除外层成对引号后再读取目录属性。

注意事项

  • Windows 支持 DIRECTORY、NMEMS；Linux 另支持 OWNER、GROUPNAME、PERMISSION。
  • 仅支持 Windows 与 Linux 操作系统。
  • 支持在 DIR= 中使用 SAS 环境变量，不支持操作系统环境变量。
  • 目录名无需加引号；宏会去掉外层成对引号。

已知风险

1. 临时变量与临时数据集冲突风险

  • 宏会临时占用固定名称的文件引用 _dummy_ 访问目录，结束时释放该文件引用。若会话中已分配同名文件引用，其原有分配会被覆盖并清除，依赖该引用的后续程序将无法再访问原文件。

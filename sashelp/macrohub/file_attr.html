名称

file_attr

简介

返回指定文件的属性值。Windows 支持 FILENAME、RECFM、LRECL、FILESIZE、MODTM、CRDTM；Linux 支持 FILENAME、FILESIZE、MODTM、OWNER、GROUPNAME、PERMISSION。返回值可直接用于 %put、%let、%if 等宏语句。

语法

%file_attr(file=<file>, attr=<attribute>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
FILE= 必需参数 无 文件的完整路径，包含文件名。支持在路径中使用 SAS 环境变量。
ATTR= 必需参数 无 待获取的文件属性名，不区分大小写。Windows 支持：
FILENAME、RECFM、LRECL、FILESIZE、MODTM、CRDTM。
Linux 支持：FILENAME、FILESIZE、MODTM、OWNER、GROUPNAME、PERMISSION。

用法示例

示例 1：获取文件名与文件大小

filename demo_txt "%sysfunc(pathname(work))\demo.txt";
data _null_;
  file demo_txt;
  put 'line1';
  put 'line2';
run;

%put NOTE: FILENAME = [%file_attr(file=%sysfunc(pathname(work))\demo.txt,attr=FILENAME)];
%put NOTE: FILESIZE = [%file_attr(file=%sysfunc(pathname(work))\demo.txt,attr=FILESIZE)];

运行结果：

NOTE: FILENAME = [.\temp\SAS Temporary Files\_TD8096_BEIJING_\demo.txt]
NOTE: FILESIZE = [14]

FILENAME 返回完整路径；文件写入两行文本后大小为 14 字节，因此 FILESIZE 返回 14。路径取决于当前 WORK 位置。

示例 2：获取创建时间与修改时间

filename demo_txt "%sysfunc(pathname(work))\demo.txt";
data _null_;
  file demo_txt;
  put 'line1';
  put 'line2';
run;

%put NOTE: MODTM = [%file_attr(file=%sysfunc(pathname(work))\demo.txt,attr=MODTM)];
%put NOTE: CRDTM = [%file_attr(file=%sysfunc(pathname(work))\demo.txt,attr=CRDTM)];

运行结果：

NOTE: MODTM = [2026年11月03日 23时00分59秒]
NOTE: CRDTM = [2026年11月03日 23时00分59秒]

MODTM 与 CRDTM 返回本地时间文本；文件刚创建，两个时间相同。

示例 3：获取记录格式与记录长度

filename demo_txt "%sysfunc(pathname(work))\demo.txt";
data _null_;
  file demo_txt;
  put 'line1';
  put 'line2';
run;

%put NOTE: RECFM = [%file_attr(file=%sysfunc(pathname(work))\demo.txt,attr=RECFM)];
%put NOTE: LRECL = [%file_attr(file=%sysfunc(pathname(work))\demo.txt,attr=LRECL)];

运行结果：

NOTE: RECFM = [V]
NOTE: LRECL = [32767]

RECFM=V 表示可变长记录；LRECL 返回 32767。这两项属性仅在 Windows 下可用。

注意事项

  • Windows 支持 FILENAME、RECFM、LRECL、FILESIZE、MODTM、CRDTM；Linux 支持 FILENAME、FILESIZE、MODTM、OWNER、GROUPNAME、PERMISSION。
  • 仅支持 Windows 与 Linux 操作系统。
  • 支持在 FILE= 中使用 SAS 环境变量。

已知风险

1. 已知但未修复的风险

  • 这是 SAS 软件的已知缺陷：使用 SAS 9.4M7 Unicode 会话且运行于 Windows 时，若 FILE= 含中文且 ATTR= 为 FILESIZE、CRDTM 或 MODTM，可能返回空值。

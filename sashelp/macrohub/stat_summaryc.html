名称

stat_summaryc

简介

对分类分析变量按 CLASS= 分组计算频数与百分比，并转置为每个分析水平一行的宽表：分组水平转置为 TRT<ID> 列，列标签为分组水平标签并按需附加 (N=#)。可选 CHISQ、FISHER、CMH、RC 假设检验，检验统计量、P 值与检验方法写入 _TESTV_、_TESTP_、_TESTM_。宏不返回值，结果写入 OUT= 数据集。

语法

%stat_summaryc(data=<dataset>, var=<variables>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 输入数据集名，仅支持数据集，且观测数必须大于 0。
OUT= 可选参数 _DATA_ 输出数据集名。
BY= 可选参数 无 BY 分组变量，可指定多个变量；每个 BY 组分别计算。
CLASS= 可选参数 无 定义分组与比较的变量，仅支持一个变量；不指定时将所有观测作为一个总体分析。
VAR= 必需参数 无 分析变量列表，多个变量以空格分隔，输出顺序与书写顺序一致。
PERCENT= 可选参数 COL 百分比计算基准，不区分大小写。
COL：列百分比（组内）。
ROW：行百分比（分析水平内）。
TOTAL：占总体百分比。
NONE：不输出百分比。
TEST= 可选参数 NONE 假设检验方法，不区分大小写。
NONE：不检验。
CHISQ：卡方检验，出现卡方警告时自动改用 Fisher 精确检验。
FISHER：Fisher 精确检验。
CMH：Cochran-Mantel-Haenszel 检验。
RC：R*C 一般关联检验。
TEST0FREQ= 可选参数 N 假设检验是否纳入频数为 0 的水平，取 Y 或 N。
ALPHA= 可选参数 0.05 假设检验的显著性水平，取值 0 至 1。
TOTCLASSID= 可选参数 0 分配给合计组的列 ID。
TOTCLASSLAB= 可选参数 Total 合计组的列标签。
TOTLEVELID= 可选参数 99 分配给合计水平的水平 ID。
TOTLEVELLAB= 可选参数 Total 合计水平的显示文本。
TOTLEVELSTAT= 可选参数 NNMISS 合计水平显示的统计量形式。
N：仅例数。
NNMISS：例数与缺失数，显示为 N(NMISS)。
NPERCENT：例数与百分比，显示为 N(PERCENT)。
PCTDENOM= 可选参数 N 百分比分母的取值方式。
TOTAL：分母包含缺失值。
N：分母仅包含非缺失观测。
SHOWDENOM= 可选参数 Y 是否在分组列标签后附加 (N=#) 文本，取 Y 或 N。
DENOMDLM= 可选参数 @ 分组标签与 (N=#) 文本之间的分隔符。
PCTFMT= 可选参数 8.1 百分比的数值格式。
DEBUG= 可选参数 0 是否保留中间数据集。
0：结束时删除中间数据集。
1：保留中间数据集以便排查。

用法示例

示例 1：生成分类变量频数表

data work.sumc1;
  length trt $1 sex $1;
  input trt $ sex $;
  datalines;
A M
A M
A M
A F
A F
B M
B F
B F
B F
;
run;

%stat_summaryc(data=work.sumc1,out=work.sum1,class=trt,var=sex)

proc print data=work.sum1(keep=_varnam_ _varlvl_ _statlab_ trt1 trt2 trt0);
run;

运行结果（WORK.SUM1）：

_varnam__varlvl__statlab_trt1trt2trt0
SEXFn(%)2(40.0)3(75.0)5(55.6)
SEXMn(%)3(60.0)1(25.0)4(44.4)
SEXTotaln(miss)5(0)4(0)9(0)

分组水平转置为 trt1（A）、trt2（B），合计水平为 trt0；_statlab_ 为 n(%) 的分析水平行，合计水平行为 n(miss)。

示例 2：增加卡方检验

data work.sumc1;
  length trt $1 sex $1;
  input trt $ sex $;
  datalines;
A M
A M
A M
A F
A F
B M
B F
B F
B F
;
run;

%stat_summaryc(data=work.sumc1,out=work.sum2,class=trt,var=sex,test=CHISQ)

proc print data=work.sum2(keep=_varnam_ _varlvl_ _testv_ _testp_ _testm_);
run;

运行结果（WORK.SUM2）：

_varnam__varlvl__testv__testp__testm_
SEXFN0.52381Fisher
SEXM..
SEXTotal..

TEST=CHISQ 出现卡方警告时自动改用 Fisher 精确检验，_testm_ 记录为 Fisher；检验结果只写在该分析变量的第一条观测上。

示例 3：使用行百分比

data work.sumc1;
  length trt $1 sex $1;
  input trt $ sex $;
  datalines;
A M
A M
A M
A F
A F
B M
B F
B F
B F
;
run;

%stat_summaryc(data=work.sumc1,out=work.sum3,class=trt,var=sex,
               percent=ROW,pctdenom=TOTAL)

proc print data=work.sum3(keep=_varlvl_ _statlab_ trt1 trt2 trt0);
run;

运行结果（WORK.SUM3）：

_varlvl__statlab_trt1trt2trt0
Fn(%)2(40.0)3(60.0)5(55.6)
Mn(%)3(75.0)1(25.0)4(44.4)
Totaln(miss)5(0)4(0)9(0)

PERCENT=ROW 以分析水平为基准计算百分比，例如 F 在 A 组中的行百分比为 2/5=40.0%；本例数据无缺失，PCTDENOM=TOTAL 不影响结果。

注意事项

  • CLASS= 仅支持一个变量；未指定或只有一个非缺失水平时，所有观测作为一个总体分析，且 TEST= 被强制设为 NONE。
  • TEST=CHISQ 出现卡方警告时自动改用 Fisher 精确检验。
  • TOTCLASSID= 与 TOTLEVELID= 取值不当时可能出错，不能与分组水平索引及合计水平索引冲突。
  • 当分析变量带自定义格式时，格式中定义但数据中未出现的水平也会纳入输出。
  • 输出每条观测对应一个 BY 组、分析变量与分析水平；分组水平转置为 TRT<ID> 列。
  • 检验统计量、P 值与检验方法写在各分析变量的第一条观测上。

已知风险

以下列出当前版本已知但未修复的问题、使用约束与冲突风险。

1. 已知但未修复的风险

  • 当 VAR= 指定的分析变量在所有观测中均为缺失时，宏运行会报中间结果数据集不存在，输出只保留元数据列，缺少 TRT* 分组列与合计行，无法得到 0(nmiss) 形式的合计结果。使用前应确认分析变量存在非缺失值。

2. 对输入参数的强假设

  • CLASS= 仅支持一个变量；未指定 CLASS= 或仅有一个非缺失水平时，所有观测作为一个总体分析，且 TEST= 被强制为 NONE。
  • TOTCLASSID= 与 TOTLEVELID= 不得与分组水平索引、分析水平索引重复；取值冲突时输出的 TRT 列名或水平排序会冲突，可能报错或结果被错误归并。

3. 临时变量与临时数据集冲突风险

  • 宏会创建并覆盖固定名称的中间数据集（名称以 STAT_SUMMARYC_ 开头），并在 DEBUG=0 时删除 WORK 中所有以 STAT_SUMMARYC_ 开头的数据集；WORK 中该前缀的自有数据集会被覆盖或误删。
  • 未指定 CLASS= 时，宏用临时变量 _CLASS_ 承担分组，并用 _BYIDX_ 记录 BY 组编号。若输入数据集已含 _CLASS_ 或 _BYIDX_，其原值会参与分组或编号计算，导致分组结果或 BY 组归属错乱。

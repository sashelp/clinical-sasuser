名称

var_exist

简介

判断指定变量是否存在于指定数据集中，并可选择校验变量类型。宏以函数方式返回数值结果：变量存在且类型符合时返回 1，否则返回 0。返回值可直接用于 %if 条件判断，也可通过 %let 或 %put 获取。

语法

%var_exist(data=<dataset>, var=<variable>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待检查的 SAS 数据集名，仅支持数据集，不支持视图。
VAR= 必需参数 无 待检查的变量名，必须符合当前 VALIDVARNAME 选项的命名规则。
TYPE= 可选参数 ALL 期望的变量类型，不区分大小写。
ALL：不校验变量类型。
C：要求为字符型。
N：要求为数值型。

用法示例

示例 1：判断变量是否存在及类型是否匹配

%put NOTE: NAME 存在 = %var_exist(data=sashelp.class,var=name);
%put NOTE: NAME 为字符型 = %var_exist(data=sashelp.class,var=name,type=C);
%put NOTE: NAME 为数值型 = %var_exist(data=sashelp.class,var=name,type=N);

运行结果：

NOTE: NAME 存在 = 1
NOTE: NAME 为字符型 = 1
NOTE: NAME 为数值型 = 0

TYPE=ALL（默认）只判断存在性，返回 1；TYPE=C 类型相符返回 1；TYPE=N 与字符型不符，返回 0。

示例 2：在条件判断中使用返回值

%if %var_exist(data=sashelp.class,var=weight)=1 %then %do;
  %put NOTE: WEIGHT 存在。;
%end;
%else %do;
  %put WARNING: WEIGHT 不存在。;
%end;

运行结果：

NOTE: WEIGHT 存在。

返回值直接参与 %if 判断；weight 存在于 sashelp.class，返回 1，因此进入 %then 分支。

示例 3：变量不存在与类型校验的返回值

%put NOTE: ABC 存在 = %var_exist(data=sashelp.class,var=abc);
%put NOTE: AGE 为数值型 = %var_exist(data=sashelp.class,var=age,type=N);

运行结果：

NOTE: ABC 存在 = 0
NOTE: AGE 为数值型 = 1

变量不存在时返回 0，不会终止程序；变量存在且类型符合时返回 1。

注意事项

  • 返回值为 1（变量存在且类型符合）或 0（不存在或类型不符）。
  • DATA= 仅支持数据集，不支持视图。
  • TYPE= 仅支持 ALL、C、N。

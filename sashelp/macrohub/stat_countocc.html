名称

stat_countocc

简介

针对发生（occurrence）数据，按 CODE= 变量的层级组合与 CLASS= 分组，计算每个组合的唯一受试者例数与事件数，并生成百分比及“例数(百分比)”文本。输出为宽表：每个 CODE 层级一行，_TOTAL_ 汇总行位于同层级首位；ns0/ne0/np0/nsp0 为合计列，ns1 起的列对应各分组。可选择进行组间假设检验。宏不返回值，结果写入 OUT= 数据集。

语法

%stat_countocc(data=<dataset>, class=<variable>, code=<variables>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 发生数据（如 AE、CM）的数据集名，仅支持数据集。
DENOM= 可选参数 &DATA. 用于计算分母的数据集名（如 ADSL），默认与 DATA= 相同。
OUT= 可选参数 _DATA_ 输出数据集名。
CLASS= 必需参数 无 定义分组分析的变量，仅支持一个变量（如 TRT）。
CODE= 必需参数 无 发生数据中的编码变量，多个变量以空格分隔，如 AEBODSYS AEDECOD 或 ATC1 ATC2 ATC3。
SUBJECT= 可选参数 USUBJID 用于计数的受试者标识变量。
UNCODE= 可选参数 UNCODED CODE= 变量缺失时用于填充的文本。
TOTCODELAB= 可选参数 _TOTAL_ 各 CODE= 变量汇总行的显示文本。
TEST= 可选参数 NONE 组间假设检验方法，不区分大小写。
NONE：不进行检验。
CHISQ：卡方检验。
FISHER：Fisher 精确检验。
AUTO：先尝试卡方检验，出现卡方警告时改用 Fisher 精确检验。
SORTCLASSNUM= 可选参数 0 排序时所依据的分组序号，0 表示合计列。
PCTFMT= 可选参数 8.1 百分比输出的数值格式。
DEBUG= 可选参数 0 是否保留中间数据集。
0：结束时删除中间数据集。
1：保留中间数据集以便排查。

注意事项

  • CLASS= 仅支持一个变量。
  • CODE= 可指定多个变量，多个变量以空格分隔。
  • 受试者例数为当前编码组合下 SUBJECT= 的唯一值数量，事件数为当前编码组合的出现次数。
  • 输出按 CODE 变量 1 的受试者例数、名称，再按 CODE 变量 2 的受试者例数、名称依次排序；SORTCLASSNUM= 指定排序所用的分组。
  • 同一 CODE 变量的各水平中，合计水平排在最前，未编码水平排在最后。
  • TEST= 仅支持 NONE、CHISQ、FISHER、AUTO。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • DENOM= 的分母须与 DATA= 的分组水平一致：每个分组水平都应包含该组全部受试者，DATA= 的 CLASS= 取值也应出现在 DENOM= 中。否则未进入分母的受试者仍计入分子，百分比可能超过 100%；分组取值不在分母范围内的记录不会进入任何分组。
  • UNCODE= 与 TOTCODELAB= 的长度不得超过 CODE= 各变量的长度。超长时值会被截断，导致不同编码被合并或汇总行无法识别，宏只输出一条 WARNING。
  • CLASS= 仅支持一个变量；CODE= 可指定多个变量并以空格分隔，按所列顺序构成层级。

2. 临时变量与临时数据集冲突风险

  • 宏会创建并覆盖固定名称的中间数据集（名称以 STAT_COUNTOCC_ 开头），并在 DEBUG=0 时删除 WORK 中所有以 STAT_COUNTOCC 开头的数据集；WORK 中该前缀的自有数据集会被覆盖或误删。DEBUG=1 时中间数据集保留。
  • 输出数据集保留由 CODE= 变量名派生的内部辅助列（以 _ 开头、以 _TYPE_ 或 _NS_ 结尾）；与下游数据集按列合并时，这些列会与同名变量冲突或被覆盖。

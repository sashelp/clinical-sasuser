名称

lib_zipvarlen

简介

批量调整指定逻辑库内所有数据集的字符变量长度，使同名变量在不同数据集之间保持一致，并压缩至实际使用的最优长度。宏不返回值，直接修改逻辑库中的数据集；该修改不可逆。SUPP_POLICY= 控制以 SUPP 开头的数据集是否参与跨数据集的最大长度计算。

语法

%lib_zipvarlen(library=<library>)

该宏为过程式宏，直接修改逻辑库中的数据集，不返回值。

参数说明

名称 类型 默认值 描述
LIBRARY= 必需参数 无 待修改的逻辑库引用名。
DELFMT= 可选参数 Y 是否删除字符变量的现有格式并改为 $n.，n 为压缩后的长度。
Y：删除并设置新格式。
N：保留现有格式。
DELINFMT= 可选参数 Y 是否删除字符变量的现有输入格式并改为 $n.，n 为压缩后的长度。
Y：删除并设置新输入格式。
N：保留现有输入格式。
SUPP_POLICY= 可选参数 FDA 以 SUPP 开头的数据集的长度策略。
FDA：这些数据集不参与跨数据集最大长度计算，每个数据集按自身数据压缩（符合 FDA 提交要求）。
CDE：所有数据集（包括 SUPP 数据集）参与跨数据集最大长度计算，同名变量取全库最大值。

用法示例

示例 1：压缩逻辑库中所有数据集的字符变量

options dlcreatedir;
libname libzv1 "%sysfunc(pathname(work))\libzv1";

data libzv1.zv1; length a $20; a='abc';      run;
data libzv1.zv2; length a $20; a='abcdefgh'; run;

%lib_zipvarlen(library=libzv1)

proc sql;
  select memname, name, length, format
  from dictionary.columns
  where libname='LIBZV1' and memname in ('ZV1','ZV2')
  order by memname;
quit;

运行结果：

数据集变量长度格式
ZV1a8$8.
ZV2a8$8.

两个数据集中变量 a 的最大使用长度分别为 3 与 8，跨数据集统一后取最大值 8，因此长度均为 8，格式改为 $8.。

示例 2：CDE 策略下统一全库最大长度

options dlcreatedir;
libname libcde "%sysfunc(pathname(work))\libcde";

data libcde.cde1;     length a $10; a='abc';                run;
data libcde.suppcde1; length a $99; a='supplemental value'; run;

%lib_zipvarlen(library=libcde,supp_policy=CDE)

proc sql;
  select memname, name, length, format
  from dictionary.columns
  where libname='LIBCDE' and memname in ('CDE1','SUPPCDE1')
  order by memname;
quit;

运行结果：

数据集变量长度格式
CDE1a18$18.
SUPPCDE1a18$18.

SUPP_POLICY=CDE 时，SUPP 数据集也参与全库最大长度计算。两个数据集的变量 a 实际最长值分别为 3 与 18，统一后均为 18。

示例 3：FDA 策略下 SUPP 不参与全库计算

options dlcreatedir;
libname libfda "%sysfunc(pathname(work))\libfda";

data libfda.fda1;     length a $10; a='abc';                run;
data libfda.suppfda1; length a $99; a='supplemental value'; run;

%lib_zipvarlen(library=libfda,supp_policy=FDA)

proc sql;
  select memname, name, length, format
  from dictionary.columns
  where libname='LIBFDA' and memname in ('FDA1','SUPPFDA1')
  order by memname;
quit;

运行结果：

数据集变量长度格式
FDA1a3$3.
SUPPFDA1a18$18.

SUPP_POLICY=FDA 时，SUPP 开头的数据集不参与全库最大长度计算；FDA1 按自身最长值 3 压缩，SUPPFDA1 按自身最长值 18 压缩。

示例 4：保留原有格式与输入格式

options dlcreatedir;
libname libfmt "%sysfunc(pathname(work))\libfmt";

data libfmt.fmt1;
  length a $20;
  attrib a format=$20. informat=$20.;
  a='abc';
run;

%lib_zipvarlen(library=libfmt,delfmt=N,delinfmt=N)

proc sql;
  select memname, name, length, format, informat
  from dictionary.columns
  where libname='LIBFMT' and memname='FMT1'
  order by memname;
quit;

运行结果：

数据集变量长度格式输入格式
FMT1a3$20.$20.

长度压缩为实际最长值 3；DELFMT=N 与 DELINFMT=N 保留了原有的 $20. 格式与输入格式。

注意事项

  • 宏会不可逆地修改逻辑库中的数据集。
  • 宏使用数据集名 lib_univarlen1；若同名数据集已存在，可能被覆盖且无法恢复。
  • SUPP_POLICY=CDE 时，字符变量长度设为全库所有数据集中的最大使用长度；FDA 时设为当前数据集中的最大使用长度。
  • DELFMT=Y 删除格式并改为 $n.，N 保留；DELINFMT=Y 删除输入格式并改为 $n.，N 保留。
  • 依赖宏 %ds_zipvarlen。

已知风险

以下列出当前版本已知但未修复的问题、使用约束与冲突风险。

1. 对输入参数的强假设

  • 宏会修改逻辑库内的全部数据集，包括 SUPP 开头的数据集；即使 SUPP_POLICY=FDA 将 SUPP 排除在全库长度计算之外，这些数据集仍会被单独压缩到自身最大长度。

2. 临时变量与临时数据集冲突风险

  • 宏会在 WORK 中创建固定名称的临时数据集 lib_univarlen1，运行结束后删除；会话中已有的同名数据集会被覆盖并删除，原数据无法恢复。

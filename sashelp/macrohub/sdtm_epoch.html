名称

sdtm_epoch

简介

按受试者从 SDTM 标准 SE 数据集中查找与记录日期匹配的 EPOCH。匹配到的 SE 记录的 SESTDTC、SEENDTC 与 EPOCH 一并写入输出数据集，输入数据集的其余变量保持不变。宏不返回值，结果写入 OUT= 数据集；OUT= 默认与 DATA= 相同，即直接更新输入数据集。

语法

%sdtm_epoch(data=<dataset>, dtc=<variable>, se=<dataset>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 输入数据集名。
SUBJECT= 可选参数 USUBJID 用于识别受试者的一个或多个变量，可指定多个变量。
DTC= 必需参数 无 记录日期时间变量，须为字符型 ISO8601 格式。
SE= 必需参数 SDTM.SE 标准 SDTM SE 数据集，应包含全部受试者，且须包含 SESTDTC、SEENDTC 与 EPOCH。
OUT= 可选参数 &DATA. 输出数据集名，默认与 DATA= 相同。

用法示例

示例 1：按 SESTDTC 边界映射 EPOCH

data work.se;
  length USUBJID $10 SESTDTC SEENDTC $20 EPOCH $30;
  USUBJID='S01'; SESTDTC='2024-01-01'; SEENDTC='2024-01-15'; EPOCH='SCRN'; output;
  USUBJID='S01'; SESTDTC='2024-01-15'; SEENDTC='2024-02-01'; EPOCH='TRT';  output;
  USUBJID='S01'; SESTDTC='2024-02-01'; SEENDTC='2024-03-01'; EPOCH='FU';   output;
run;

data work.vs;
  length USUBJID $10 VSDTC $20;
  USUBJID='S01'; VSSEQ=1; VSDTC='2024-01-05'; output;
  USUBJID='S01'; VSSEQ=2; VSDTC='2024-01-15'; output;
  USUBJID='S01'; VSSEQ=3; VSDTC='2024-02-10'; output;
run;

%sdtm_epoch(data=work.vs, se=work.se, dtc=VSDTC, out=work.vs_ep);

proc print data=work.vs_ep noobs;
  var USUBJID VSSEQ VSDTC SESTDTC SEENDTC EPOCH;
run;

运行结果（WORK.VS_EP）：

USUBJIDVSSEQVSDTCSESTDTCSEENDTCEPOCH
S0112024-01-052024-01-012024-01-15SCRN
S0122024-01-152024-01-152024-02-01TRT
S0132024-02-102024-02-012024-03-01FU

VSDTC=2024-01-05 位于 SCRN 区间 [2024-01-01, 2024-01-15) 内；2024-01-15 等于下一个 EPOCH 的 SESTDTC，按起始日包含归入 TRT；2024-02-10 位于 FU 区间 [2024-02-01, 2024-03-01) 内。宏同时把匹配到的 SE 记录的 SESTDTC、SEENDTC 写入输出。

示例 2：边界、空档与最后一段 SEENDTC 缺失

data work.se2;
  length USUBJID $10 SESTDTC SEENDTC $20 EPOCH $30;
  USUBJID='S01'; SESTDTC='2024-01-01'; SEENDTC='2024-01-10'; EPOCH='SCRN'; output;
  USUBJID='S01'; SESTDTC='2024-01-20'; SEENDTC='2024-02-10'; EPOCH='TRT';  output;
  USUBJID='S02'; SESTDTC='2024-02-20'; SEENDTC='';           EPOCH='TRT';  output;
run;

data work.vs2;
  length USUBJID $10 VSDTC $20;
  USUBJID='S01'; VSSEQ=1; VSDTC='2024-01-01'; output;
  USUBJID='S01'; VSSEQ=2; VSDTC='2024-01-15'; output;
  USUBJID='S01'; VSSEQ=3; VSDTC='2024-01-20'; output;
  USUBJID='S01'; VSSEQ=4; VSDTC='2024-02-10'; output;
  USUBJID='S01'; VSSEQ=5; VSDTC='2024-02-25'; output;
  USUBJID='S02'; VSSEQ=6; VSDTC='2024-02-25'; output;
run;

%sdtm_epoch(data=work.vs2, se=work.se2, dtc=VSDTC, out=work.vs2_ep);

proc print data=work.vs2_ep noobs;
  var USUBJID VSSEQ VSDTC SESTDTC SEENDTC EPOCH;
run;

运行结果（WORK.VS2_EP）：

USUBJIDVSSEQVSDTCSESTDTCSEENDTCEPOCH
S0112024-01-012024-01-012024-01-10SCRN
S0122024-01-15
S0132024-01-202024-01-202024-02-10TRT
S0142024-02-102024-01-202024-02-10TRT
S0152024-02-25
S0262024-02-252024-02-20TRT

2024-01-15 落在 SCRN 结束日 2024-01-10 与 TRT 起始日 2024-01-20 之间的空档，不满足任一映射条件，三个变量均为空。2024-02-10 等于最后一个 SEENDTC，归入 TRT；2024-02-25 晚于最后一个 SEENDTC，不映射，日志输出 WARNING: Row 5: VSDTC is later than the last SEENDTC.。S02 的最后一个 SEENDTC 缺失，2024-02-25 不早于最后一个 SESTDTC 2024-02-20，归入 TRT。

示例 3：省略 OUT= 时直接更新输入数据集

data work.vs3;
  length USUBJID $10 VSDTC $20;
  USUBJID='S01'; VSSEQ=1; VSDTC='2024-01-05'; output;
  USUBJID='S01'; VSSEQ=2; VSDTC='2024-02-10'; output;
run;

%sdtm_epoch(data=work.vs3, se=work.se, dtc=VSDTC);

proc print data=work.vs3 noobs;
  var USUBJID VSSEQ VSDTC SESTDTC SEENDTC EPOCH;
run;

运行结果（WORK.VS3）：

USUBJIDVSSEQVSDTCSESTDTCSEENDTCEPOCH
S0112024-01-052024-01-012024-01-15SCRN
S0122024-02-102024-02-012024-03-01FU

未指定 OUT= 时默认使用 &DATA.，结果直接写回 WORK.VS3：VSSEQ、VSDTC 保留，新增 SESTDTC、SEENDTC 与 EPOCH。

示例 4：使用多个 SUBJECT= 变量作为匹配键

data work.se4;
  length USUBJID $10 SUBJID $6 SESTDTC SEENDTC $20 EPOCH $30;
  USUBJID='S01'; SUBJID='001'; SESTDTC='2024-01-01'; SEENDTC='2024-01-15'; EPOCH='SCRN'; output;
  USUBJID='S01'; SUBJID='001'; SESTDTC='2024-01-15'; SEENDTC='2024-02-01'; EPOCH='TRT';  output;
  USUBJID='S02'; SUBJID='002'; SESTDTC='2024-02-10'; SEENDTC='2024-02-20'; EPOCH='SCRN'; output;
run;

data work.vs4;
  length USUBJID $10 SUBJID $6 VSDTC $20;
  USUBJID='S01'; SUBJID='001'; VSSEQ=1; VSDTC='2024-01-05'; output;
  USUBJID='S01'; SUBJID='001'; VSSEQ=2; VSDTC='2024-01-20'; output;
  USUBJID='S02'; SUBJID='002'; VSSEQ=1; VSDTC='2024-02-12'; output;
run;

%sdtm_epoch(data=work.vs4, se=work.se4, subject=USUBJID SUBJID,
             dtc=VSDTC, out=work.vs4_ep);

proc print data=work.vs4_ep noobs;
  var USUBJID SUBJID VSSEQ VSDTC SESTDTC SEENDTC EPOCH;
run;

运行结果（WORK.VS4_EP）：

USUBJIDSUBJIDVSSEQVSDTCSESTDTCSEENDTCEPOCH
S0100112024-01-052024-01-012024-01-15SCRN
S0100122024-01-202024-01-152024-02-01TRT
S0200212024-02-122024-02-102024-02-20SCRN

SUBJECT=USUBJID SUBJID 指定两个键变量，宏按组合键在 SE 中查找：S01/001 的两条记录分别映射到 SCRN 与 TRT，S02/002 映射到 SCRN。

注意事项

  • 记录日期 DTC= 满足以下任一条件时映射：不早于 SESTDTC 且早于 SEENDTC；等于最后一个 SEENDTC；不早于最后一个 SESTDTC 且最后一个 SEENDTC 缺失。
  • DTC= 为字符型 ISO8601 格式；含缺失日期部分时不做填补，按非缺失部分参与映射；若有多个 EPOCH 匹配，取最后一个。
  • SE= 应为 SDTM 标准 SE 数据集，包含 SESTDTC、SEENDTC 与 EPOCH，并应包含全部受试者。

已知风险

以下列出当前版本已知但未修复的问题、使用约束与冲突风险。

1. 已知但未修复的风险

  • 超出最后一个 SEENDTC 的记录会逐条写入 WARNING: Row ... is later than the last SEENDTC.；批量数据下日志噪声较大。
  • 部分日期按非缺失部分参与映射，多个匹配取最后一个；该行为依赖下述“相邻 SE 连续”假设，SE 存在空档或重叠时可能取不到预期 EPOCH。

2. 对输入参数的强假设

  • SE 数据集：同一受试者相邻两条 SE 记录须满足本条 SEENDTC = 下一条 SESTDTC（无空档、无重叠）；SE 应包含全部受试者，并包含 SESTDTC、SEENDTC、EPOCH，且仅最后一个 SEENDTC 可为空。DATA 中的受试者若不在 SE 中，记录不映射；非末段 SEENDTC 缺失、SESTDTC 缺失或同一受试者 SESTDTC 重复、EPOCH 区间重叠时，不在宏的约定范围内。
  • DTC= 必须是字符型 ISO8601；宏按字符串与前缀比较，要求年、月、日各段定长书写，如 2024-03、2024-03-01、2024-03-01T09:30。
  • SUBJECT= 变量应同时存在于 DATA 与 SE，且取值含义一致；多个键变量按组合键匹配。

3. 临时变量与临时数据集冲突风险

  • 宏会使用临时变量 _RC_、_RC_NEXT_、_HASH_RST_；若输入数据集已有同名变量，会被覆盖并在输出时删除，原值丢失。
  • 宏会把匹配到的 SESTDTC、SEENDTC 与 EPOCH 写入输出。若输入数据集已含这些变量，原值会被清空后按映射结果重写；未匹配到 EPOCH 时该列为空。
  • 宏使用固定中间数据集 WORK.SDTM_EPOCH1；若 WORK 中已有同名数据集，会被覆盖并在宏运行结束时删除，原数据丢失。
  • 规避：调用前确认 WORK 中不存在 SDTM_EPOCH1，输入数据集避免使用上述临时变量名。

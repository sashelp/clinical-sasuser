名称

var_nlevel

简介

返回指定变量在数据集中的不同取值个数。字符变量按去掉尾部空格后的值比较，仅尾部空格不同的取值视为同一水平；数值变量按 GETVARN() 返回的字符表示比较；格式不参与水平计数。INCLUDEMISSING=N（默认）时不计缺失值；为 Y 时字符缺失值计为 1 个水平，数值的普通缺失（.）与各特殊缺失（.A 至 .Z、._）分别计为不同水平。

语法

%var_nlevel(data=<dataset>, var=<variable>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待统计的 SAS 数据集名，仅支持数据集，不支持视图。
VAR= 必需参数 无 待统计水平数的变量名。
INCLUDEMISSING= 可选参数 N 是否将缺失值计入水平数，不区分大小写。
N：不计缺失值。
Y：计入缺失值；字符缺失计 1 个水平，数值的普通缺失与各特殊缺失分别计数。

用法示例

示例 1：统计字符变量的水平数

%put NOTE: SEX 水平数 = %var_nlevel(data=sashelp.class,var=sex);

运行结果：

NOTE: SEX 水平数 = 2

Sex 只有 M、F 两个取值，宏返回 2。

示例 2：包含缺失值时的计数

data work.miss;
  length c1 $10;
  c1='A';  n1=1;  output;
  c1='A '; n1=1;  output;
  c1='';   n1=.;  output;
  c1='B';  n1=.A; output;
  c1='C';  n1=2;  output;
run;

%put NOTE: C1 不含缺失 = %var_nlevel(data=work.miss,var=c1);
%put NOTE: C1 含缺失   = %var_nlevel(data=work.miss,var=c1,includemissing=Y);
%put NOTE: N1 不含缺失 = %var_nlevel(data=work.miss,var=n1);
%put NOTE: N1 含缺失   = %var_nlevel(data=work.miss,var=n1,includemissing=Y);

运行结果：

NOTE: C1 不含缺失 = 3
NOTE: C1 含缺失   = 4
NOTE: N1 不含缺失 = 2
NOTE: N1 含缺失   = 4

C1 中 'A' 与 'A ' 仅尾部空格不同，视为同一水平，因此不含缺失为 3 个水平（A、B、C），含缺失为 4 个。N1 中数值 1、2 与缺失 .、.A 分别计数，不含缺失为 2，含缺失为 4。

示例 3：统计数值变量的水平数

%put NOTE: AGE 水平数 = %var_nlevel(data=sashelp.class,var=age);

运行结果：

NOTE: AGE 水平数 = 6

sashelp.class 中 Age 取值为 11 至 16，共 6 个不同水平；默认不计算缺失值。

注意事项

  • 返回变量的不同取值个数；字符变量仅尾部空格不同视为同一水平，格式不影响水平计数。
  • INCLUDEMISSING=N 不计缺失；Y 时字符缺失计 1 个水平，数值的普通缺失与各特殊缺失分别计数。
  • 逐观测读取数据，处理时间与观测数及水平数成正比；数值变量按 GETVARN() 的字符表示比较，超出显示精度的差异不会被区分。
  • DATA= 仅支持数据集，不支持视图。
  • 依赖宏 %var_exist。

已知风险

1. 临时变量与临时数据集冲突风险

  • 宏会按变量的不同取值数量创建 _SEEN_1、_SEEN_2 … 全局宏变量，运行结束后既不清除也不复位。若会话中已有同名宏变量，其值会被覆盖；取值水平数越多，全局符号表中累积的宏变量越多。

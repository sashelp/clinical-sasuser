名称

ds_attr

简介

返回指定数据集的属性值。宏根据属性名自动选择 SAS 函数 ATTRC() 或 ATTRN()：字符型属性返回文本，数值型属性返回数值。返回值可直接用于 %put、%let、%if 等宏语句。

语法

%ds_attr(data=<dataset>, attr=<attribute>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待查询的 SAS 数据集名，仅支持数据集，不支持视图。
ATTR= 必需参数 无 待获取的属性名，不区分大小写，须为 ATTRC() 或 ATTRN() 支持的属性，常用值包括：
NOBS、NLOBS、NLOBSF、NVARS：观测数与变量数。
LABEL、TYPE、ENCODING、ENGINE：数据集标签、成员类型、编码、引擎。
SORTEDBY、SORTLVL、SORTSEQ：排序信息。
CHARSET、COMPRESS、DATAREP、ENCRYPT、LIB、MEM、MODE、MTYPE：其他数据集属性。

用法示例

示例 1：获取观测数与变量数

%put NOTE: NOBS  = %ds_attr(data=sashelp.class,attr=nobs);
%put NOTE: NVARS = %ds_attr(data=sashelp.class,attr=nvars);

运行结果：

NOTE: NOBS  = 19
NOTE: NVARS = 5

sashelp.class 有 19 个观测、5 个变量，宏分别返回 19 与 5。

示例 2：获取数据集标签与编码

data work.labeled(label='测试数据集');
  x=1;
run;

%put NOTE: LABEL = [%ds_attr(data=work.labeled,attr=label)];
%put NOTE: ENCODING = [%ds_attr(data=work.labeled,attr=encoding)];

运行结果：

NOTE: LABEL = [测试数据集]
NOTE: ENCODING = [utf-8  Unicode (UTF-8)]

LABEL 返回数据集的标签；ENCODING 返回数据集存储编码，本次为 UTF-8 会话，因此返回 utf-8 Unicode (UTF-8)。

示例 3：区分 NOBS、NLOBS 与 NLOBSF

data work.deleted;
  do i=1 to 5; output; end;
run;

data work.deleted;
  modify work.deleted;
  if i=3 then remove;
run;

%put NOTE: NOBS   = %ds_attr(data=work.deleted,attr=nobs);
%put NOTE: NLOBS  = %ds_attr(data=work.deleted,attr=nlobs);
%put NOTE: NLOBSF = %ds_attr(data=work.deleted(where=(i=1)),attr=nlobsf);

运行结果：

NOTE: NOBS   = 5
NOTE: NLOBS  = 4
NOTE: NLOBSF = 1

NOBS 仍为 5（包含被 REMOVE 删除的观测）；NLOBS 返回删除后的 4；NLOBSF 在 WHERE=(i=1) 下返回满足条件的 1。

注意事项

  • 获取观测数时：一般使用 NOBS；数据集用 REMOVE 修改过时使用 NLOBS；带 WHERE= 数据集选项时使用 NLOBSF。
  • DATA= 仅支持数据集，不支持视图。
  • ATTR= 须为 ATTRC() 或 ATTRN() 支持的属性。

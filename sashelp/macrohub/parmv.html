parmv

宏参数校验与标准化错误信息

名称

parmv

简介

对宏参数进行校验，并生成统一格式的错误信息。支持必填检查、允许值列表、正整数或非负整数检查、多值检查、大小写转换、默认值以及强制宏变量存在；调用宏需定义局部宏变量 PARMERR 来接收错误标志。

用法示例

示例 1：在自定义宏中校验参数

%macro demo(x=);
  %local parmerr;
  %parmv(x,_req=1,_val=POSITIVE)
  %if &parmerr %then %goto quit;
  %put NOTE: x=&x.;
  %quit:
%mend demo;

%demo(x=10)
%demo(x=-1)
%demo(x=)

运行结果：

NOTE: x=10
ERROR: DEMO user error.
ERROR: -1 is not a valid value for the X parameter.
ERROR: Only POSITIVE integers are allowed.
ERROR: DEMO user error.
ERROR: A value for the X parameter is required.
ERROR: Allowable values are: POSITIVE.

x=10 通过 POSITIVE 整数校验并输出；x=-1 不满足校验，x= 触发必填错误。宏输出标准化 ERROR 信息并把 PARMERR 置为 1，示例宏随即跳转到 quit，不再执行后续逻辑。

注意事项

  • 本程序为未经验证的开源宏程序，使用时风险自负。

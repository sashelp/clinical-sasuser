名称

ds_varlist

简介

返回指定数据集的变量名列表，变量名以空格分隔。可通过 TYPE= 过滤字符型或数值型变量，通过 PATTERN= 使用 Perl 正则表达式过滤变量名。返回的变量名保持数据集中的原始大小写，可直接用于 KEEP=、DROP= 或作为其他宏的参数。

语法

%ds_varlist(data=<dataset>)

该宏为函数式宏，返回值会直接替换到调用位置，因此必须放在 %put、%let、%if 等宏语句中使用，不能作为独立语句提交。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 待读取变量列表的 SAS 数据集名，仅支持数据集，不支持视图。
TYPE= 可选参数 无 变量类型过滤条件，不区分大小写。
不指定：返回全部变量。
C：仅返回字符型变量。
N：仅返回数值型变量。
PATTERN= 可选参数 无 变量名过滤的正则表达式，需包含分隔符，例如 /^A/；支持 Perl 正则语法。

用法示例

示例 1：获取全部变量

%put NOTE: 全部变量 = [%ds_varlist(data=sashelp.class)];

运行结果：

NOTE: 全部变量 = [Name Sex Age Height Weight]

宏按数据集变量顺序返回变量名列表，多个变量以空格分隔，并保持原始大小写。

示例 2：按类型筛选变量

%put NOTE: 字符变量 = [%ds_varlist(data=sashelp.class,type=C)];
%put NOTE: 数值变量 = [%ds_varlist(data=sashelp.class,type=N)];

运行结果：

NOTE: 字符变量 = [Name Sex]
NOTE: 数值变量 = [Age Height Weight]

TYPE=C 只返回字符型变量，TYPE=N 只返回数值型变量，变量名之间以空格分隔。

示例 3：使用正则表达式筛选

%put NOTE: 匹配变量 = [%ds_varlist(data=sashelp.class,pattern=/^(Age|Height)$/)];

运行结果：

NOTE: 匹配变量 = [Age Height]

PATTERN= 中的 /^(Age|Height)$/ 只匹配完整的 Age 与 Height 变量名，因此返回 Age Height。

注意事项

  • 返回的变量名保持原始大小写。
  • TYPE= 仅支持 C、N 或留空。
  • PATTERN= 为正则表达式过滤条件。
  • DATA= 仅支持数据集，不支持视图。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • PATTERN= 必须带定界符（例如 /^num/）；不带定界符时会被判为非法正则表达式并终止。

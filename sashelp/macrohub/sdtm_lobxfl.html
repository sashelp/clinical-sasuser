名称

sdtm_lobxfl

简介

在指定的 SDTM 数据集中，按受试者与 BY= 分组筛选合格记录：结果变量非缺失，且记录日期不晚于首次研究药物给药日期。组内按记录日期排序，将最新的一条合格记录标记为 BLFL='Y'，其余记录保持空白。宏不返回值，结果写入 OUT= 数据集；OUT= 默认与 DATA= 相同，即直接更新输入数据集。

语法

%sdtm_lobxfl(data=<dataset>, var=<variable>, dtc=<variable>, blfl=<variable>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称 类型 默认值 描述
DATA= 必需参数 无 输入数据集名。
VAR= 必需参数 &DOMAIN.ORRES 用于判断记录是否非缺失的变量。字符型排除空白、NA、ND 与 UK；数值型排除普通缺失与特殊缺失值。
DTC= 必需参数 &DOMAIN.DTC 记录日期时间变量，须为字符型 ISO8601 格式。
BLFL= 必需参数 &DOMAIN.LOBXFL 要创建的基线标志变量名。
DOMAIN= 可选参数 无 域名称，用于推导 VAR=、DTC=、BY= 与 BLFL= 的默认值，例如 DOMAIN=LB 对应 LBORRES、LBDTC、LBTESTCD、LBLOBXFL。
OUT= 可选参数 &DATA. 输出数据集名，默认与 DATA= 相同。
BY= 可选参数 &DOMAIN.TESTCD 受试者内的分组变量，可指定多个变量，例如 LBTESTCD；每个 BY 组生成一个基线标志。留空时每个受试者只生成一个基线标志。
SUBJECT= 可选参数 USUBJID 受试者标识变量，只接受一个变量。
RFDTC= 可选参数 SDTM.DM.RFXSTDTC 首次研究药物给药的参考日期时间，支持三种形式：
LIB.DATASET.VARIABLE：已存在数据集的变量。
DATASET.VARIABLE：WORK 数据集的变量。
VARIABLE：输入数据集自身的变量。

用法示例

示例 1：按检验项目生成基线标志

data work.dm;
  length USUBJID $8 RFXSTDTC $20;
  USUBJID='S01'; RFXSTDTC='2024-01-10'; output;
  USUBJID='S02'; RFXSTDTC='2024-01-10'; output;
run;

data work.lb;
  length USUBJID $8 LBTESTCD $8 LBDTC $20 LBORRES $8;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-05'; LBORRES='10'; output;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-09'; LBORRES='20'; output;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-12'; LBORRES='30'; output;
  USUBJID='S01'; LBTESTCD='AST'; LBDTC='2024-01-08'; LBORRES='5';  output;
  USUBJID='S02'; LBTESTCD='ALT'; LBDTC='2024-01-05'; LBORRES='NA'; output;
  USUBJID='S02'; LBTESTCD='ALT'; LBDTC='2024-01-08'; LBORRES='40'; output;
run;

%sdtm_lobxfl(data=work.lb,out=work.lb_fl,var=LBORRES,dtc=LBDTC,by=LBTESTCD,
              blfl=LOBXFL,subject=USUBJID,rfdtc=work.dm.rfxstdtc);

proc sort data=work.lb_fl; by USUBJID LBTESTCD LBDTC; run;
proc print data=work.lb_fl noobs;
  var USUBJID LBTESTCD LBDTC LBORRES LOBXFL;
run;

运行结果（WORK.LB_FL）：

观测USUBJIDLBTESTCDLBDTCLBORRESLOBXFL
1S01ALT2024-01-0510
2S01ALT2024-01-0920Y
3S01ALT2024-01-1230
4S01AST2024-01-085Y
5S02ALT2024-01-05NA
6S02ALT2024-01-0840Y

RFDTC= 取 WORK.DM.RFXSTDTC，两名受试者的首次给药日期均为 2024-01-10。S01 的 ALT 记录中，2024-01-12 晚于参考日期，不参与标记，因此最新合格记录 2024-01-09 被标记；AST 组只有一条记录，直接标记。S02 的 NA 为无效结果，被排除后由 2024-01-08 获得标记。

示例 5：数值型结果变量与特殊缺失值

data work.dm;
  length USUBJID $8 RFXSTDTC $20;
  USUBJID='S01'; RFXSTDTC='2024-01-10'; output;
run;

data work.lb5;
  length USUBJID $8 LBTESTCD $8 LBDTC $20;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-05'; LBSTRESN=10;  output;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-07'; LBSTRESN=0;   output;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-09'; LBSTRESN=.;   output;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-10'; LBSTRESN=.A;  output;
  USUBJID='S01'; LBTESTCD='ALT'; LBDTC='2024-01-11'; LBSTRESN=99;  output;
run;

%sdtm_lobxfl(data=work.lb5,out=work.lb5_fl,var=LBSTRESN,dtc=LBDTC,by=LBTESTCD,
              blfl=LOBXFL,subject=USUBJID,rfdtc=work.dm.rfxstdtc);

proc sort data=work.lb5_fl; by USUBJID LBTESTCD LBDTC; run;
proc print data=work.lb5_fl noobs;
  var USUBJID LBTESTCD LBDTC LBSTRESN LOBXFL;
run;

运行结果（WORK.LB5_FL）：

观测USUBJIDLBTESTCDLBDTCLBSTRESNLOBXFL

2S01ALT2024-01-070Y
3S01ALT2024-01-09.
4S01ALT2024-01-10A

VAR=LBSTRESN 为数值型，. 与特殊缺失 .A 均被排除；0 是有效值，可以成为候选记录。2024-01-11 数值为 99，但晚于参考日期，不参与标记，因此最新合格记录 2024-01-07 被标记。

注意事项

  • 参与标记的记录须同时满足：VAR= 非缺失，DTC= 非缺失且不晚于 RFDTC=。
  • 字符型 VAR= 排除空白、NA、ND 与 UK；数值型 VAR= 排除普通缺失与特殊缺失值。
  • DTC= 与 RFDTC= 按字符串截断比较，ISO8601 部分日期按公共前缀比较，仅日期值可与日期时间值的日期部分比较。
  • 多个合格记录的 DTC= 并列最新时，按 SUBJECT=、BY= 及输入顺序排序后取最后一条标记。
  • BY= 未指定时每个受试者只标记一条；指定多个 BY= 变量时每个 BY 组标记一条。
  • SUBJECT= 只接受一个变量。
  • RFDTC= 支持 LIB.DATASET.VARIABLE、DATASET.VARIABLE、VARIABLE 三种形式。
  • 输出按 SUBJECT= 与 BY= 排序，工作变量 _RFDTC_ 保留。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • RFDTC= 指向其他数据集时，该数据集须包含 DATA= 中每个受试者。缺少某个受试者时，该受试者的参考日期为空，其全部记录都不会获得基线标志，且宏不输出提示。
  • DTC= 与 RFDTC= 仅按日期部分比较。给药当天给药后的记录同样满足“不晚于首次给药日期”，可能被选为基线记录；是否可接受取决于数据的日期粒度，需要时应在调用前处理。
  • 同一 BY 组内多条合格记录的 DTC= 相同时，只标记排序中的最后一条。输入记录顺序变化会改变被标记的基线记录。

2. 临时变量与临时数据集冲突风险

  • 宏会创建并覆盖固定名称的中间数据集 WORK.SDTM_LOBXFL1 与 WORK.SDTM_LOBXFL2，并在宏运行结束时删除；WORK 中已有的同名数据集会被覆盖并删除，原数据丢失。
  • 宏会创建临时变量 _DTC_ 与 _RFDTC_。若输入数据集已有同名变量，原值会被覆盖，且 _DTC_ 在输出时被删除、_RFDTC_ 保留以方便溯源。当 RFDTC= 指向其他数据集时，输入中与参考日期变量同名的列也会从输出中删除。
  • 若输入数据集已含 BLFL= 指定的变量，其原值会先被清空再按本宏逻辑重算，原有基线标志不会保留。

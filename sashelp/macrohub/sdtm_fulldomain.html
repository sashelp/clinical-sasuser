名称

sdtm_fulldomain

简介

将父域数据集与 SUPP 数据集按受试者标识及 IDVAR/IDVARVAL 合并，把 SUPP 中的 QNAM 转置为列（列标签取 QLABEL），生成包含补充信息的完整域数据集。宏不返回值，结果写入 OUT= 数据集。若 SUPP= 为空、数据集不存在、观测数为 0 或所有 SUBJECT= 变量值均缺失，则直接复制父域数据集。

语法

%sdtm_fulldomain(domain=<domain>)

该宏为过程式宏，结果写入 OUT= 数据集，不返回值。

参数说明

名称 类型 默认值 描述
DOMAIN= 必需参数 无 域名称，例如 AE、CM，用于生成默认的父域、SUPP 与输出数据集名。
PARENT= 可选参数 SDTM.&DOMAIN. 父域数据集名，默认使用 SDTM.<DOMAIN>。
SUBJECT= 可选参数 USUBJID 受试者标识变量，可指定多个变量；默认为 USUBJID，也可使用 SUBJID。
SUPP= 可选参数 SDTM.SUPP&DOMAIN. 补充域数据集名，默认使用 SDTM.SUPP<DOMAIN>。留空表示不需要合并 SUPP。
OUT= 可选参数 &DOMAIN. 输出数据集名，默认为 &DOMAIN.。

用法示例

示例 1：合并父域与 SUPP 数据集

data work.ae;
  length usubjid $8 aeterm $20;
  usubjid='S01'; aeseq=1; aeterm='Headache'; output;
  usubjid='S01'; aeseq=2; aeterm='Nausea';   output;
  usubjid='S02'; aeseq=1; aeterm='Fever';    output;
run;

data work.suppae;
  length usubjid $8 idvar $8 idvarval $8 qnam $8 qlabel $40 qval $20;
  usubjid='S01'; idvar='AESEQ'; idvarval='1'; qnam='AESEV'; qlabel='Severity'; qval='MILD';     output;
  usubjid='S01'; idvar='AESEQ'; idvarval='1'; qnam='AESER'; qlabel='Serious';  qval='N';        output;
  usubjid='S01'; idvar='AESEQ'; idvarval='2'; qnam='AESEV'; qlabel='Severity'; qval='MODERATE'; output;
run;

%sdtm_fulldomain(domain=AE,parent=work.ae,supp=work.suppae,out=work.ae_full)

proc print data=work.ae_full;
run;

运行结果（WORK.AE_FULL）：

观测usubjidaetermaeseqidvaridvarvalAESEVAESER
1S01Headache1AESEQ1MILDN
2S01Nausea2AESEQ2MODERATE
3S02Fever1

SUPPAE 中的 QNAM 被转置为列：AESEV 与 AESER，列标签取自 QLABEL；IDVAR 与 IDVARVAL 保留在输出中用于关联。父域中 S02 没有对应的 SUPP 记录，因此补充变量为空。

示例 2：使用 SUBJID 作为受试者标识

data work.ae2;
  length subjid $8 aeterm $20;
  subjid='S01'; aeseq=1; aeterm='Headache'; output;
  subjid='S02'; aeseq=1; aeterm='Fever';    output;
run;

data work.suppae2;
  length subjid $8 idvar $8 idvarval $8 qnam $8 qlabel $40 qval $20;
  subjid='S01'; idvar='AESEQ'; idvarval='1'; qnam='AESEV'; qlabel='Severity'; qval='MILD'; output;
run;

%sdtm_fulldomain(domain=AE,parent=work.ae2,supp=work.suppae2,
                 subject=subjid,out=work.ae2_full)

proc print data=work.ae2_full;
run;

运行结果（WORK.AE2_FULL）：

观测subjidaetermaeseqidvaridvarvalAESEV
1S01Headache1AESEQ1MILD
2S02Fever1

SUBJECT=SUBJID 指定受试者标识变量后，合并键改为 SUBJID 与 ID 变量，输出中不再出现 USUBJID。

示例 3：不合并 SUPP 数据集

data work.ae3;
  length usubjid $8 aeterm $20;
  usubjid='S01'; aeseq=1; aeterm='Headache'; output;
  usubjid='S02'; aeseq=1; aeterm='Fever';    output;
run;

%sdtm_fulldomain(domain=AE,parent=work.ae3,supp=,out=work.ae3_full)

proc print data=work.ae3_full;
run;

运行结果（WORK.AE3_FULL）：

观测usubjidaetermaeseq
1S01Headache1
2S02Fever1

SUPP= 留空时，宏直接将父域数据集复制为输出数据集，不生成补充变量。

注意事项

  • SUPP= 未指定、SUPP 数据集不存在、观测数为 0 或所有 SUBJECT= 变量值均缺失时，宏直接复制父域数据集。
  • 父域数据集须按 SUBJECT= 变量与 ID 变量排序，ID 变量为 SUPP 数据集中 IDVAR 的取值。
  • SUPP 数据集须按 SUBJECT=、IDVAR、IDVARVAL 排序。
  • 依赖宏 %var_coexist 与 %var_attr。

已知风险

以下列出当前版本的使用约束与冲突风险。

1. 对输入参数的强假设

  • 父域须按 SUBJECT= 变量与 ID 变量排序，SUPP 须按 SUBJECT=、IDVAR、IDVARVAL 排序。任一数据集未按上述键排序时，合并会失败中止或产生错行的结果。
  • SUPP 中 IDVAR 只能有一个不同取值，且该取值必须是父域中实际存在的变量；IDVARVAL 须能按父域 ID 变量的类型解析。出现多个 IDVAR、父域缺少对应 ID 变量或 IDVARVAL 无法转换时，SUPP 记录无法关联到正确的父域记录，部分补充变量会丢失。

2. 临时变量与临时数据集冲突风险

  • 宏会创建固定名称的中间数据集 WORK.SDTM_FULLDOMAIN1，并在宏运行结束时删除；WORK 中已有的同名数据集会被覆盖并删除，原数据丢失。
  • SUPP 的 QNAM 会转成同名变量与父域横向合并。若 QNAM 与父域已有变量同名，父域原值会被 SUPP 值覆盖，且不产生提示。

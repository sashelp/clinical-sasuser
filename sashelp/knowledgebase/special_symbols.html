如何绘制带有特殊符号的图形？

五个位置、三种写法：UNICODE 行内格式到处都能用，直接写入取决于文件编码，SUP/SUB 只在 INSET 的自由文本里有效。

结论

特殊符号（≥ ≤ ≈ ≠、上下标、♀ ♂ ☀ 这类）在图形里有五个位置可以出现：自由文本、图形文本、图例、轴标签、轴刻度值。写法有三种：直接写入、SUP/SUB 行内格式、UNICODE 行内格式。核心规矩只有一条：SUP/SUB 只对 INSET 的自由文本有效，其余四个位置写了也不认，会原样印出一串 SUP(*ESC*){sup '2'}。UNICODE 行内格式五个位置通吃，是最稳的写法。

先记住三种写法

以平方符号 ² 为例：

写法怎么写适用
直接写入把 ² 当普通字符打进字符串五个位置都行，但受文件编码影响，最不稳
SUP / SUB 行内格式(*ESC*){sup '2'}只在 INSET 里有效
UNICODE 行内格式(*ESC*){unicode '00b2'x}五个位置都行，纯 ASCII 书写，最稳

(*ESC*) 是 SAS 的转义符，它告诉 SAS 后面不是普通文字，而是一段带效果的指令。上标用 {sup '…'}，下标用 {sub '…'}，特殊字符用 {unicode 'xxxx'x}，xxxx 是这个字符的十六进制 Unicode 编码。

五个位置，三种写法能不能用

位置直接写入SUP / SUBUNICODE
自由文本（INSET）可以可以可以
图形文本（TEXT、SCATTER 的 datalabel=）可以不行可以
图例（KEYLEGEND）可以不行可以
轴标签（label=）可以不行可以
轴刻度值（values=）可以不行可以

这张表我在 SAS 9.4 上逐个跑图确认过：SUP 在 TEXT、图例、轴标签、刻度值四处都会原样打成 SUP__SUP_2_SUP_ 这样的字面量，日志里不报错，所以不看图根本发现不了。

不管用哪种写法，字体一定要指定

图形输出到结果窗口（HTML）时，默认字体未必包含你要的符号，缺字形就显示成 □。TEXTATTRS=、VALUEATTRS=、LABELATTRS= 里用 family= 指定一个覆盖范围大的字体，比如：

textattrs=(family="微软雅黑")

位置一：自由文本（INSET）

INSET 是画在画布任意位置的说明文字，不受坐标约束，所以三种写法都能用。

proc sgplot data=fig1 noborder noautolegend;
  series x=x y=y;
  inset
    "直接写入²"
    "SUP(*ESC*){sup '2'}"
    "UNICODE(*ESC*){unicode '00b2'x}"
    /noborder position=topright textattrs=(family="微软雅黑");
  xaxis offsetmin=0.2 offsetmax=0.2;
  yaxis offsetmin=0.2 offsetmax=0.2;
run;

三段文字分别用三种写法，输出都是 ²。noborder 去掉边框，position=topright 放右上角。

位置二：图形文本（TEXT / SCATTER）

图形文本按坐标画，用 TEXT 语句，或者 SCATTER 的 datalabel=。这里有个 SAS 特有的做法：文字不直接写在数据里，而是用 format 把文本“格式化”上去，业内叫 TrafficLighting 技巧。

proc format;
  value glab
  1="直接写入²"
  2="SUP(*ESC*){sup '2'}"
  3="UNICODE(*ESC*){unicode '00b2'x}"
  ;
run;

proc sgplot data=fig2 noborder noautolegend;
  series x=x y=y/markers markerattrs=(size=7pt);
  text x=x y=y text=glab/textattrs=(family="微软雅黑");
  xaxis offsetmin=0.2 offsetmax=0.2;
  yaxis offsetmin=0.2 offsetmax=0.2;
  format glab glab.;
run;

跑出来只有第一段和第三段正常，第二段印出的是 SUP 开头的原始字符串。换成 SCATTER 的 datalabel= 也一样。

这两种画法还有个位置差异，实测能看到：TEXT 默认把文字放在坐标点的左侧，而它量不出 SUP 字符串的真实长度，文字就会盖住那个点；SCATTER 的 datalabel= 会主动绕开坐标点，把标签放到旁边，量长度也更准。要标注散点，优先用 datalabel=。

位置三：图例（KEYLEGEND）

proc sgplot data=fig2 noborder;
  series x=x y=y;
  scatter x=x y=y/group=glab name="sca" nomissinggroup;
  xaxis offsetmin=0.2 offsetmax=0.2;
  yaxis offsetmin=0.2 offsetmax=0.2;
  keylegend "sca"/valueattrs=(family="微软雅黑");
  format glab glab.;
run;

要点是三步：group= 把散点分组，name= 给这条语句起个引用名，KEYLEGEND "sca" 再把它画进图例。nomissinggroup 表示不画缺失组别的那一项。

位置四：轴标签（label=）

proc sgplot data=fig2 noborder noautolegend;
  series x=x y=y;
  scatter x=x y=y/x2axis;
  xaxis offsetmin=0.2 offsetmax=0.2 label="直接写入²" labelattrs=(family="微软雅黑");
  x2axis offsetmin=0.2 offsetmax=0.2 label="SUP(*ESC*){sup '2'}" labelattrs=(family="微软雅黑");
  yaxis offsetmin=0.2 offsetmax=0.2 label="UNICODE(*ESC*){unicode '00b2'x}" labelattrs=(family="微软雅黑");
run;

顺便演示了第二条 X 轴：SCATTER 加 x2axis 选项就用上轴画图，再用 X2AXIS 给上轴设标签。这里 SUP 同样失效。

位置五：轴刻度值（values=）

刻度值默认由 SAS 决定画哪些，也可以自己指定。只给 values= 时按值列表显示；同时给 values= 和 valuesdisplay= 时，前者管画哪些刻度、后者管每个刻度显示什么文字。

proc format;
  value glab
  -0.4="直接写入²"
  0="SUP(*ESC*){sup '2'}"
  0.4="UNICODE(*ESC*){unicode '00b2'x}"
  ;
run;

proc sgplot data=fig2 noborder noautolegend;
  series x=x y=y;
  xaxis offsetmin=0.2 offsetmax=0.2 values=(-0.4,0,0.4)
        valueattrs=(family="微软雅黑") fitpolicy=rotate;
  yaxis offsetmin=0.2 offsetmax=0.2;
  format x glab.;
run;

fitpolicy=rotate 让刻度文字在横向放不下时倾斜 45° 排，图窄的时候很有用。同样，SUP 在这一格也不认。

实在找不到字符时：注释数据集

有些符号没有合适的上下标字符。比如要在轴标签里写 AUC0-∞，∞ 没有下标形式，Unicode 里找不到对应编码。这时可以画两段文字拼出来：用内置宏 %sgtext 建一张注释数据集，把 “AUC” 和 “0-∞” 用不同字号、不同位置分别画，再把原轴标签留空。

data anno;
  %sganno;
  %sgtext(label="AUC",x1=51,y1=3,textsize=11,justify="center");
  %sgtext(label="0-∞",x1=56.5,y1=2,textsize=8,justify="center");
run;

proc sgplot data=fig2 noborder noautolegend sganno=anno;
  series x=x y=y;
  scatter x=x y=y;
  xaxis offsetmin=0.2 offsetmax=0.2 label=" ";
  yaxis offsetmin=0.2 offsetmax=0.2;
run;

sganno= 指定注释数据集，label=" " 一个空格把原标签清掉，腾出位置。字号和偏移量要反复试，比较费手工。

还有一条更轻的路子：改用 GTL 绘图，把轴标签留空，用 ENTRY 语句在同样位置画文本。思路上的变通，比调注释数据集省事。

几个容易踩的坑

  • SUP/SUB 只在 INSET 有效。这一条最值钱。在 TEXT、图例、轴标签、刻度值里写 {sup}，SAS 不报错，只是把它当普通字符串印出来。
  • 直接写入会被文件编码坑。我实测时用 UTF-8 存程序、在 EUC-CN 的会话里跑，² 直接变成了乱码；把程序文件转成 GBK 再跑就正常。所以同一段程序换台机器、换个编码就可能坏掉，UNICODE 写法只用 ASCII，最抗折腾。
  • 图形文本、图例、刻度值要借助 FORMAT。不是把符号直接写进数据集，而是用 PROC FORMAT 定义好文本，再套在变量上。
  • 别忘了 family=。漏了字体设置，符号可能显示成 □，看起来像“没生效”，其实是字体缺字形。
  • TEXT 会压住坐标点。它默认把文字放左侧，遇到量不准长度的字符串就盖上去；标注散点用 SCATTER 的 datalabel= 更稳。
  • 注释数据集是最后的兜底。位置和字号要手工调，图形尺寸一改还得重调，能用字符解决就别用它。

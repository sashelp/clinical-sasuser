知识库 / 客户端

Enterprise Guide 在双屏下“卡死”了，是程序挂了还是窗口跑到屏幕外了？

多半是窗口被挪到了看不见的位置；按 Alt+Space 再按 M，用方向键把它拉回来，8.1 和 8.2 还可以直接重置布局。

结论

接上第二块屏幕、或者拔掉外接屏之后，Enterprise Guide 的某个窗口可能还记着旧位置，落在当前桌面范围之外。表现出来是“查询生成器特别慢”“任务卡住不动”“点了没反应”，其实程序在正常运行，只是窗口你看不见。先用键盘把窗口召唤回来，别急着重装。

长什么样

典型表现有三种，经常一起出现：

  • 查询生成器或者某个任务打开时明显变慢，像在等什么
  • 代码或任务跑着跑着就不动了
  • 界面锁死、点了没响应，但任务管理器里 EG 的 CPU 占用是正常的

最后一条是关键区分：如果是真卡死，CPU 通常会掉到 0 或者飙到很高；如果 CPU 有轻微波动，多半只是窗口位置问题。

把窗口找回来

最快的一招：选中那个窗口，按 Alt+Spacebar+M 进入移动模式，然后按方向键把它拖回可见区域，按回车确认。

如果这一招没反应，按右边这几步走，本质上是同一件事，只是分了步：

  1. 按 Alt+Spacebar，弹出窗口的系统菜单
  2. 按下方向键，选中“移动”
  3. 按 Enter，进入移动模式
  4. 按右方向键，告诉系统你开始移动了
  5. 移动鼠标，看窗口有没有跟着出来

重置布局

在 Enterprise Guide 8.1 和 8.2 里，可以直接把窗口布局恢复成默认值：

  1. 打开 View 菜单
  2. 选择 Reset to default layout
  3. 弹窗里点 Restore

这个操作会把所有停靠窗口的位置、大小恢复成初始状态。代价是你自己调整过的布局会丢，所以先试前面的移动方法，不行再用这个。

什么时候才是真的卡住

如果窗口能正常移动、布局也重置过，界面还是没反应，那就不是位置问题了。这时候去看日志和任务管理器：

  • 任务管理器里 EG 进程的 CPU 长期为 0，内存不涨——可能真的死锁了，重启 EG
  • CPU 一直很高——任务在跑，只是慢，去查数据量和程序写法
  • 网络盘断开、SAS 服务器连不上——界面会长时间等待，看起来像卡死，实际是超时

知识库 / SDTM

SDTM 中能允许 --ORRES 和 --STAT 同时为空的记录吗？

不允许。Findings 类记录要么有结果、要么有状态，两者互斥，至少得填一个。

结论

在 Findings 和 Findings About 这两类里，一条记录必须“有结果”或“有状态”，两者不能同时空着——这种记录既没测量值、也没解释为啥没值，是不合规的。P21 和 CDISC 一致性校验会直接报缺失结果或缺失状态。

规则从哪来

  • SDTM 模型对 --STAT 的定义：用来表示“这个问题没被问、检查没做、或者做了但没出结果”，取值只能是 NOT DONE 或空。
  • SDTMIG 的约定：--ORRES 只有在 --STAT = "NOT DONE" 或 --DRVFL = "Y"（派生）的时候才允许空；反过来 --ORRES 有值，--STAT 就必须空。也就是说两者互斥，而且至少填一个。

判断顺序

拿到一条 Findings 记录，--ORRES 和 --STAT 这么填

四种情形对照

情形--ORRES--STAT--REASND其他要求
正常有结果值空空--STRESC 必填；数值型再填 --STRESN
单项未做（含做了但没结果）空NOT DONE有原因就填--ORRESU / --STRESC / --STRESN / --STRESU 全空
整个 panel 未做空NOT DONE有原因就填--TESTCD = "--ALL"，--TEST 与 --CAT 填组名
派生结果空空空必须 --DRVFL = "Y"，且 --STRESC / --STRESN 有值

几个容易踩的坑

  • CRF 上勾了“NA / UNKNOWN / 不适用”：这些是 null flavor，属于“值”，要写进 --ORRES（比如 NOT APPLICABLE），--STAT 还是空——不能两列都空。
  • 采血失败、样本溶血、仪器故障：属于“做了但没出结果”，按定义要填 NOT DONE，理由放 --REASND（比如 SPECIMEN HEMOLYZED）。
  • 整次访视缺失、CRF 也没标“是否做了”：通常不建记录。SDTMIG 的原则是别凭空造 NOT DONE，只有源数据明确回答“未做”时才建 NOT DONE 记录。
  • 只填了 --STRESC/--STRESN、--ORRES 空：这不叫双空，但必须补 --DRVFL = "Y"，否则会被报 --ORRES 缺失。
  • --STAT 的取值：只允许 NOT DONE，别写 ND、MISSING、NA。
  • 个别域模板本身没有 --STAT（比如部分肿瘤域）：这条规则不适用，按那个域的 assumptions 处理，缺失评估通常是不建记录，而不是硬塞一个 --STAT。

FDA 有个特例：QS 逻辑跳转题

FDA 技术一致性指南要求 QS 里的“逻辑跳转题”必须交记录，写法是 QSSTAT = "NOT DONE"、QSREASND = "LOGICALLY SKIPPED ITEM"，结果是空的；只有当量表手册明确规定了跳转题怎么赋分时，才会出现 QSSTAT 和 QSORRES 同时有值。这是 FDA 的特别要求，属于“互斥”规则的例外，得在 cSDRG 里说明。

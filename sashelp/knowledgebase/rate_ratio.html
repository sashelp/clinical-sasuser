知识库 / 统计分析

“每 1000 人年 3.2 例”这种率，模型怎么建、率比怎么估？

用 log 链接的 Poisson 或负二项模型，把暴露量的对数做成 offset 放进模型；率比就是 exp(参数)，用 LSMEANS 的 ILINK 和 EXP 直接能出。

结论

率不是比例——比例的分子包含在分母里，上限是 1；率的分子是事件数、分母是暴露量（人年、随访时间、保单数），取值可以大于 1。所以率不能直接当二分类结局建模。正确做法是把暴露量的对数作为 offset 放进 Poisson 或负二项模型，让模型去解释“单位暴露下的平均事件数”，再用 LSMEANS / ILINK 把结果反变换成率，用 DIFF EXP 得到率比。

模型长什么样

记 μ 是事件数的均值，n 是暴露量，模型写成：

log(μ / n) = x′β

挪一下就是 log(μ) = log(n) + x′β。右边多出来的 log(n) 就是 offset——它是个系数固定为 1 的项，不参与估计，只负责把“事件数”换算成“每单位暴露的事件数”。

在 PROC GENMOD 里，用 OFFSET= 指定一个已经取过对数的变量：

data insure;
   input n c car$ age;
   carnum=1;
   if car="medium" then carnum=2;
   if car="large"  then carnum=3;
   ln = log(n);
   datalines;
500   42  small  1
1200  37  medium 1
100    1  large  1
400  101  small  2
500   73  medium 2
300   14  large  2
;
run;

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
run;

这里 c 是索赔件数，n 是投保人数，ln 就是投保人数的对数。模型估的是“人均索赔率”，不是“索赔件数”。

把率估出来

最省事的是 LSMEANS。默认输出的是 log 尺度上的最小二乘均值，加 ILINK 才会反变换成率，加 CL 给置信区间：

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
   lsmeans age / ilink cl;
run;

输出里 Mean 那一列就是率：AGE=1 的人群是 0.03156，置信区间 (0.02395, 0.0416)。这是对车型各水平取平均之后的率。

要具体人群的率，三条路

LSMEANS 给的是边际平均。如果只想要某个组合的率（比如 AGE=1 且 CAR=SMALL），有三种写法，结果完全一致。

用 PROC PLM 打分

先在 GENMOD 里用 STORE 把模型存下来，再到 PLM 里 SCORE。NOOFFSET 是关键：它让打分时不算 offset，得到的就是率而不是事件数。再配 ILINK 反变换。

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
   store out=insmodel;
run;

proc plm source=insmodel;
   score data=insure out=inspred
         pred stderr lclm uclm / nooffset ilink;
run;

AGE=1、CAR=SMALL 的率是 0.0716，置信区间 (0.0553, 0.0927)。

用 OUTPUT 语句自己算

这条路人稍微绕一点，但不需要 PLM。要注意 P= 给的是计数的预测值，XBETA= 给的是 log 计数的线性预测值（里面含 offset）。所以要先减掉 offset 得到 log 率，再取指数：

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
   output out=out p=pcount xbeta=xb stdxbeta=std;
run;

data predrates;
   set out;
   obsrate = c/n;
   lograte = xb - ln;
   prate   = exp(lograte);
   lcl     = exp(lograte - probit(.975)*std);
   ucl     = exp(lograte + probit(.975)*std);
   keep n c car age prate lcl ucl;
run;

因为 log 率和 log 计数只差一个常数，标准误是一样的，可以直接拿 stdxbeta 去构造区间。

用 ESTIMATE 语句

写法和前面 CONTRAST 那一篇的道理一样，指出这个人群对应哪几个参数：

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
   estimate "Rate: age=1, small" intercept 1 age 1 0 car 0 0 1;
run;

L'Beta Estimate 是 log 率（−2.6367），Mean Estimate 是率（0.0716）。缺点是每条 statement 只能算一个人群，人群一多就很啰嗦。

率比怎么估

率比就是两个率的比。在 log 尺度上它是差，所以 LSMEANS 加 DIFF 给差，再加 EXP 就把差变成了比：

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
   lsmeans age / ilink diff exp cl;
run;

AGE=1 相对 AGE=2 的率比是 0.2672，置信区间 (0.2047, 0.3487)，检验 p<0.0001。注意方向：差分表给的是“行水平减列水平”，谁减谁要看表头，别把比值报反。

也可以用 ESTIMATE 直接对参数下手。age 1 -1 是 log 率比，加 / exp 得到率比：

proc genmod data=insure;
   class car age;
   model c = car age / dist=poisson link=log offset=ln;
   estimate "Age Rate Ratio" age 1 -1 / exp;
run;

想要的量怎么写注意
某个人群的率LSMEANS / ILINK CL给的是对其它因子取平均后的率
特定组合的率PROC PLM 的 SCORE / NOOFFSET ILINK忘了 NOOFFSET 就变成估事件数
两组的率比LSMEANS / DIFF EXP CL方向由水平顺序决定
率的差（不是比）另见 SAS Note 37344 的做法差和比的解释不一样，别混
过离散明显时DIST=NEGBINPoisson 的方差假设是均值等于方差，实际数据经常不成立

写方案时的两个提醒

  • offset 必须是暴露量的对数，不是暴露量本身。常见错误是直接写 offset=n，模型就变成了 log(μ) = n + xβ，完全不是率模型。
  • 随访时间不齐的时候，率比和 OR 不是一回事。事件罕见时两者接近，事件一多就分开了。要报的是率比，就别拿 logistic 的 OR 顶上去。

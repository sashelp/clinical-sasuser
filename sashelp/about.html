关于本站

临床试验 SAS 编程的本地可视化知识库

站点用途

SAS/HELP 面向临床试验数据分析场景，把日常编程中最常用的宏、结论与图形模板集中到一个可直接浏览的静态站点中，便于查询、复用与团队共享。

宏程序库

收录可复用的 SAS 宏，提供参数说明、用法示例与依赖包下载。

知识库

沉淀 SDTM、ADaM、SAS 编程与统计分析中的常见问题及结论。

图形库

提供 GTL 图形模板与 RTF 输出，覆盖条形图、箱线图、散点图、折线图与生存曲线。

站点为纯静态页面，无后端依赖，可直接从本地打开，也可部署到 GitHub Pages。页面内容由 sashelp\site.json 与 codehub 下的源文件驱动。

意见与建议

发现内容错误、希望补充某个宏或图形模板，或对站点有其他建议，欢迎通过 GitHub Issues 留言。提交前需要登录 GitHub 账号；也可以直接发送邮件。

在 GitHub 提交意见 查看已有讨论 发送邮件
